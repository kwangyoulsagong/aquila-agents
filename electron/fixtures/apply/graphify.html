Graphify: turn a codebase into a knowledge graph your agent can query

Fixture written for Aquila's T64 tests; it paraphrases the idea, not a real page.

Graphify is an agent skill. It reads a folder of code and Markdown, extracts files, symbols, imports and the notes that mention them, and writes a graph (graphify-out/graph.json) plus a short report. The agent then asks the graph ("what calls this?", "which docs explain this module?") instead of opening dozens of files, which saves context and tokens on large repos.

Setup

  1. Install the skill into .claude/skills/graphify and mention it in CLAUDE.md / AGENTS.md so the agent knows to query the graph first.
  2. Add a hook that rebuilds the graph after commits so it never goes stale.
  3. Add alias gfy="graphify ." to your ~/.zshrc.
  4. The extractor runs on Python 3.11 with tree-sitter grammars.
