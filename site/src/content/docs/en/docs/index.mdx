Aquila Agents is a macOS app that holds many **real terminal sessions** — `claude`, `codex` and your shell — across
many projects, in one window. Status dots show which agent is working, done, or waiting for you, and notifications
bring you back when one needs input.

It embeds the CLIs you already installed. Your login, `CLAUDE.md`, hooks, MCP servers and slash commands work
exactly as they do in Terminal; Aquila never rebuilds chat or permission prompts.

## What you can do

<CardGrid>
  <Card title="See who needs you" icon="warning">
    Orange means an agent waits for input. <kbd>⌘J</kbd> jumps there, longest wait first.
  </Card>
  <Card title="Work side by side" icon="seti:pipeline">
    Split into up to four panes, each its own session, across projects.
  </Card>
  <Card title="Review what changed" icon="document">
    The changes panel shows the agent's diff live; comment on a line and paste it back.
  </Card>
  <Card title="Keep notes next to code" icon="pencil">
    Markdown in your repos becomes a graph and an editor, with agent edits shown as diffs.
  </Card>
</CardGrid>
