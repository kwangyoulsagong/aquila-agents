Aquila Agents는 여러 프로젝트의 **실제 터미널 세션**(`claude`, `codex`, 셸)을 창 하나에 모으는 macOS 앱이에요.
상태 점으로 어떤 에이전트가 일하는지, 끝났는지, 나를 기다리는지 보여 주고, 입력이 필요하면 알림으로 불러요.

이미 설치한 CLI를 그대로 품어요. 로그인, `CLAUDE.md`, 훅, MCP 서버, 슬래시 명령이 터미널에서와 똑같이 동작하고,
Aquila는 채팅이나 권한 확인을 다시 만들지 않아요.
