**프로젝트**는 폴더예요. 보통 git 저장소고, 사이드바에 한 줄로 보여요. 프로젝트에서 여는 세션은 모두 그 폴더에서
시작해요. 프로젝트는 **그룹**에 들어가요(처음엔 회사, 개인).

<Shot id="projects" caption="그룹별 프로젝트. 줄마다 세션 상태 점이 보여요." />

## 프로젝트 추가하기

방법은 세 가지예요. 어느 쪽이든 마지막엔 작은 창에서 **이름**(기본은 폴더 이름), **그룹**, **Claude 계정**을
확인하고 **추가**를 눌러요.

- **사이드바:** 프로젝트 목록 아래 **+ 프로젝트 추가**를 누르고 **내 Mac의 폴더…**를 골라요.
- **끌어다 놓기:** Finder에서 폴더를 사이드바 아무 곳에나 끌어다 놓아요. 여러 개를 놓으면 첫 번째만 써요.
- **명령 팔레트:** <kbd>⌘K</kbd>를 누르고 **프로젝트 추가**를 실행해요. 메뉴 막대의 **파일 ▸ 프로젝트 추가…**도 돼요.

새 프로젝트가 바로 선택돼요.

<Aside type="tip">
  **+ 프로젝트 추가 → 원격 서버(SSH)…**로는 다른 컴퓨터의 폴더를 추가해요.
  [원격 서버(SSH)](/ko/docs/agents/remote-ssh/)를 보세요.
</Aside>

## 프로젝트 사이를 오가기

- 사이드바에서 프로젝트를 클릭해요.
- <kbd>⌘1</kbd>부터 <kbd>⌘9</kbd>로 처음 아홉 개 중 하나로 바로 가요. 몇 번이 어느 프로젝트인지는 메뉴 막대
  **윈도우 ▸ 프로젝트**에서 볼 수 있어요.
- <kbd>⌘K</kbd>를 누르고 이름 일부를 입력해요. 그룹이나 경로로도 찾아져요.

프로젝트를 고르면 그 프로젝트의 탭이 보여요. 분할된 화면 중 이미 그 프로젝트를 보여주는 곳이 있으면 그 화면으로
포커스가 가요.

## 프로젝트 설정 바꾸기

프로젝트를 오른쪽 클릭하고 **프로젝트 설정…**을 골라요(지금 프로젝트라면 <kbd>⌘K</kbd> → **프로젝트 설정…**).
**저장**을 눌러야 적용돼요.

| 설정 | 하는 일 |
|---|---|
| **이름** | 사이드바, 탭, 알림에 보이는 이름. |
| **폴더** | 세션이 시작하는 곳. **바꾸기…**로 새 폴더를 골라요. 열린 세션은 원래 폴더에서 계속되고, 새 세션부터 새 폴더를 써요. 두 프로젝트가 한 폴더를 같이 쓸 수는 없어요. |
| **그룹** | 사이드바의 어느 그룹에 둘지. |
| **Claude 계정** | 새 Claude 세션이 쓸 Claude 로그인. [Claude 계정](/ko/docs/agents/claude-accounts/)을 보세요. |
| **기본 에이전트** | Claude, Codex, 셸 중 하나. 탭 바의 **+**와 빈 화면이 이걸 먼저 열어요. |
| **기본 브랜치** | 워크트리의 새 브랜치가 여기서 시작해요. 비우면 지금 브랜치에서 시작해요. |
| **포트 시작 번호** | 세션에 `PORT`로 넘겨요. 워크트리마다 10씩 더해서, 여러 워크트리의 dev 서버가 부딪치지 않아요. 1024–65000 사이 숫자예요. |
| **셋업 스크립트** | 새 워크트리를 만들 때 한 번, 에이전트보다 먼저 실행돼요. 예: `npm ci`. |
| **실행 명령** | 실행 패널의 dev 서버·워처. 한 줄에 하나씩 `이름: 명령`. [실행](/ko/docs/agents/run/)을 보세요. |
| **열 앱** | 프로젝트 메뉴의 **…에서 열기**에 쓸 앱. Finder(기본), Visual Studio Code, Cursor, Zed, WebStorm, IntelliJ IDEA, Sublime Text, Xcode, Terminal, iTerm. |

기본 브랜치, 셋업 스크립트, 포트 시작 번호는 [워크트리](/ko/docs/agents/worktrees/)를 쓸 때 의미가 있어요. 원격
프로젝트에는 없어요. 워크트리, 미리보기, 다른 앱에서 열기는 로컬 전용이에요.

## 에디터에서 폴더 열기

프로젝트를 오른쪽 클릭하고 **Finder에서 열기**를 골라요(**열 앱** 설정에 따라 **Cursor에서 열기** 등으로 바뀌어요).
<kbd>⌘K</kbd>에도 지금 프로젝트에 대한 같은 명령이 있어요.

## 이름 바꾸기, 그룹 옮기기, 제거하기

프로젝트를 오른쪽 클릭하면:

- **이름 바꾸기…**로 이름을 바꿔요.
- **그룹 ▸**에서 다른 그룹으로 옮기거나, **새 그룹…**을 만들어 옮겨요.
- **Claude 계정 ▸**에서 새 Claude 세션이 쓸 계정을 바꿔요.
- **사이드바에서 제거…**는 Aquila에서만 빼요. 열린 세션은 닫혀요. **폴더와 파일은 그대로예요.** 디스크에는
  아무것도 손대지 않아요.

그룹 이름을 오른쪽 클릭하면 **이름 바꾸기…**, **위로 이동** / **아래로 이동**, **새 그룹…**, **그룹 삭제**(비어
있을 때만)가 있어요.

## 순서 바꾸기

프로젝트 줄을 위아래로 끌어요. 다른 줄 위에 놓으면 그 앞이나 뒤로, 그룹 이름(또는 빈 그룹) 위에 놓으면 그 그룹의
맨 끝으로 가요. 빈 그룹도 계속 보여서 그 안에 놓을 수 있어요.

<Aside type="note">
  <kbd>⌘1</kbd>–<kbd>⌘9</kbd>는 `config.json`에 저장된 순서를 따라요. 한 그룹 안에서는 보이는 순서와 같지만, 그룹이
  여러 개일 때 번호가 예상과 다르면 **윈도우 ▸ 프로젝트**에서 확인하세요.
</Aside>

## 어디에 저장되나요

프로젝트와 그룹은 `~/.aquila/config.json`에 저장돼요. 홈 폴더 아래 경로는 `~/…`로 저장해요. 직접 고칠 필요는
없지만 고칠 수도 있어요. [설정 파일](/ko/docs/reference/config/)을 보세요.
