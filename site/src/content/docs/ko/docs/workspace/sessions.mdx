**세션**은 프로젝트 폴더에서 돌아가는 진짜 터미널 하나예요. Claude Code, Codex, 또는 그냥 셸이에요. 세션마다
터미널 위 탭 바에 탭이 하나씩 생겨요.

<Shot id="sessions" caption="탭으로 열린 세션. 탭마다 상태 점이 있고, +는 프로젝트의 기본 에이전트를 열어요." />

## 세션 열기

먼저 프로젝트를 고르고:

| 키 | 여는 것 |
|---|---|
| <kbd>⌘T</kbd> | Claude |
| <kbd>⇧⌘T</kbd> | Codex |
| <kbd>⌥⌘T</kbd> | 셸 |

세션은 포커스된 화면에 열리고 키보드 입력을 받아요. 이렇게 열 수도 있어요.

- 탭 바 끝의 **+**를 눌러요. 프로젝트의 **기본 에이전트**가 열려요([프로젝트 설정](/ko/docs/workspace/projects/#프로젝트-설정-바꾸기)에서
  바꾸지 않았다면 Claude).
- **+를 오른쪽 클릭**하면 메뉴가 떠요. **Claude 열기**, **Codex 열기**, **셸 열기**, **워크트리에서 열기…**
  ([워크트리](/ko/docs/agents/worktrees/) 참고).
- 빈 화면(예: 아직 세션이 없는 프로젝트)에서는 가운데의 **Claude 열기**, **Codex 열기**, **셸 열기**를 눌러요.
- <kbd>⌘K</kbd>를 누르고 같은 명령을 실행해요.

## 실제로 무엇이 실행되나요

Aquila는 CLI를 흉내 내지 않아요. **설치된 `claude`나 `codex`를 그대로** 로그인 셸을 거쳐 프로젝트 폴더에서 진짜
터미널로 실행해요. 그래서:

- 로그인, 요금제, 토큰 사용량은 모두 CLI 그대로예요.
- `CLAUDE.md`, `AGENTS.md`, MCP 서버, 슬래시 명령, 권한 확인, 셸 alias가 터미널에서와 똑같이 동작해요.
- 에이전트가 끝나도 탭은 닫히지 않고 같은 폴더의 셸로 남아요.

Claude 세션에는 딱 하나를 더해요. `--settings`로 넘기는 작은 설정 파일(`~/.aquila/claude-hooks.<port>.json`)이에요.
Claude가 작업 중인지, 기다리는지, 끝났는지 Aquila에 알려 주는 hooks가 들어 있어서
[상태 점](/ko/docs/workspace/status/)을 보여줄 수 있어요. Aquila가 연 세션에서만 쓰여요. 내 `~/.claude` 설정은
절대 바꾸지 않고, 터미널의 `claude`에도 영향이 없어요.

세션마다 `AQUILA_TAB_ID` 같은 환경 변수도 몇 개 넘겨요. 프로젝트에 포트 시작 번호가 있으면 `PORT`도 넘겨요.

## 탭

탭에는 왼쪽부터 이런 게 보여요.

- [상태 점](/ko/docs/workspace/status/)
- 제목: Claude는 첫 프롬프트의 첫 줄, 워크트리 세션은 브랜치, 그 밖에는 종류(Claude, Codex, 셸)이고, 종류는
  작은 배지로도 보여요
- 기다리는 중이면 기다린 시간(`12분`)
- Claude라면 컨텍스트 게이지와 계정 배지

기다리는 탭에 마우스를 올리면 무엇을 묻고 있는지 보여요.

### 탭 이름 바꾸기

제목을 두 번 클릭하고 이름을 입력한 뒤 Enter를 눌러요. <kbd>Esc</kbd>는 취소, 비우면 자동 제목으로 돌아가요.
<kbd>⌘K</kbd> → **세션 이름 바꾸기**도 같아요. 이름은 앱을 다시 열어도 남아요.

### 탭 옮기기

탭을 탭 바에서 좌우로 끌어 순서를 바꿔요. 터미널 영역으로 끌어서 화면에 놓을 수도 있어요. 화면 **가장자리**에
놓으면 그 화면이 나뉘고, **가운데**에 놓으면 그 화면에 보여요. [화면 분할](/ko/docs/workspace/split-panes/)을 보세요.

## 세션 사이를 오가기

- 탭을 클릭해요.
- <kbd>⌘J</kbd>로 나를 기다리는 세션으로 가요. 다른 프로젝트여도 돼요.
- <kbd>⌘K</kbd>를 누르고 세션 제목 일부를 입력해요.

보고 있지 않은 세션도 계속 돌아가고 스크롤백도 남아요(셸 10,000줄, Claude·Codex 5,000줄).

## 세션 닫기

아래 중 하나면 세션이 끝나고 탭이 닫혀요.

- <kbd>⌘W</kbd>로 포커스된 세션을 닫아요. 빈 분할 화면에서는 <kbd>⌘W</kbd>가 그 화면을 닫아요.
- 탭의 **×**를 누르거나, 탭을 가운데 버튼으로 클릭해요.
- <kbd>⌘K</kbd> → **세션 닫기**.

<Aside type="caution">
  탭을 닫으면 그 안의 프로세스가 묻지 않고 바로 멈춰요. 작업 중이던 에이전트도 그 자리에서 멈춰요. 입력창이나 노트
  에디터 안에서는 <kbd>⌘W</kbd>가 세션을 닫지 않아요.
</Aside>

닫은 Claude·Codex 대화를 다시 열려면 [세션 기록](/ko/docs/agents/session-history/)(<kbd>⌘Y</kbd>)에서 새 탭으로
이어서 열어요.
