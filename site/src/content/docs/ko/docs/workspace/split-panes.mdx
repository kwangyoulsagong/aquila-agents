창을 나누면 여러 세션을 한 번에 볼 수 있어요. 코드를 쓰는 Claude 옆에 리뷰하는 Codex를, 에이전트 옆에 테스트를
돌리는 셸을 두는 식이에요. 화면은 **최대 4개**이고, 화면마다 세션 하나를 보여줘요.

<Shot id="split" caption="나란히 놓인 화면 두 개. 포커스된 화면의 세션이 지금 탭이에요." />

## 화면 나누기

| 키 | 동작 |
|---|---|
| <kbd>⌘D</kbd> | 오른쪽으로 분할 |
| <kbd>⇧⌘D</kbd> | 아래로 분할 |

포커스된 화면이 둘로 나뉘고, 새로 생긴 빈 화면에 포커스가 가요. <kbd>⌘T</kbd>, <kbd>⇧⌘T</kbd>, <kbd>⌥⌘T</kbd>로
세션을 열거나 빈 화면의 버튼을 눌러요. 화면이 이미 4개면 나뉘지 않아요.

<kbd>⌘K</kbd> → **오른쪽으로 분할** / **아래로 분할**도 돼요.

### 탭을 끌어서 나누기

탭 바의 탭을 터미널 영역으로 끌어요.

- 화면 **가장자리**(왼쪽, 오른쪽, 위, 아래)에 놓으면 그쪽으로 화면이 나뉘어요.
- 화면 **가운데**에 놓으면 그 화면에 이 세션을 대신 보여줘요.

그 세션이 이미 다른 화면에 보이고 있었다면 옮겨 오고, 원래 화면은 닫혀요.

## 여러 프로젝트 섞어 보기

분할 배치는 프로젝트가 아니라 창 전체에 속해요. 그래서 화면마다 다른 프로젝트의 세션을 보여줄 수 있어요. 다른
프로젝트의 화면에 포커스를 주면 사이드바와 탭 바도 그 프로젝트로 바뀌어요.

사이드바에서 프로젝트를 고르면, 이미 그 프로젝트를 보여주는 화면으로 포커스가 가요. 없으면 포커스된 화면에 그
프로젝트의 마지막 세션이 보여요.

## 화면 사이를 오가기

화면을 클릭하거나 <kbd>⌥⌘</kbd>와 화살표를 눌러요.

| 키 | 포커스 이동 |
|---|---|
| <kbd>⌥⌘←</kbd> | 왼쪽 |
| <kbd>⌥⌘→</kbd> | 오른쪽 |
| <kbd>⌥⌘↑</kbd> | 위 |
| <kbd>⌥⌘↓</kbd> | 아래 |

포커스된 화면의 세션이 지금 탭이고, 입력도 거기로 가요.

화면마다 머리줄이 있어요. 세션의 상태 점, 제목, 프로젝트(워크트리면 브랜치도), 그리고 확대·닫기 버튼이 있어요.

## 한 화면 확대하기

<kbd>⇧⌘↩</kbd>를 누르거나, 화면 머리줄을 두 번 클릭하거나, 머리줄의 **⤢**를 눌러요. 그 화면이 가득 차고 나머지는
그대로 기다려요. 한 번 더 누르면(또는 **⤡**) 원래대로 돌아와요. 새로 분할해도 확대가 풀려요.

### 전체 창

<kbd>⇧⌘F</kbd>를 누르면 사이드바와 탭까지 숨기고 포커스된 화면만 보여줘요. <kbd>⇧⌘F</kbd>를 다시 누르면 나가요.

<Aside type="note">
  <kbd>Esc</kbd>로는 확대나 전체 창에서 나가지 않아요. <kbd>Esc</kbd>는 에이전트를 멈추는 데 쓰는 CLI 몫이에요.
  들어갈 때 쓴 단축키로 나가요.
</Aside>

<Shot id="zoom" caption="화면 하나를 가득 키운 모습." />

## 화면 크기 바꾸기

- 두 화면 사이의 경계선을 끌어요.
- 또는 <kbd>⌥⇧⌘</kbd>와 화살표로 포커스된 화면의 경계선을 옮겨요.
- **경계선을 두 번 클릭**하면 다시 반반이 돼요.

## 화면 닫기

화면 머리줄의 **×**를 누르거나, 빈 화면에서 <kbd>⌘W</kbd>를 눌러요. 화면을 닫으면 배치에서만 빠지고, 보여주던
세션은 탭으로 계속 돌아가요. 세션 자체를 끝내려면 <kbd>⌘W</kbd>로 탭을 닫아요.

## 분할 단축키 모음

| 키 | 동작 |
|---|---|
| <kbd>⌘D</kbd> / <kbd>⇧⌘D</kbd> | 오른쪽 / 아래로 분할(최대 4개) |
| <kbd>⌥⌘←</kbd> <kbd>⌥⌘→</kbd> <kbd>⌥⌘↑</kbd> <kbd>⌥⌘↓</kbd> | 옆 분할로 이동 |
| <kbd>⇧⌘↩</kbd> | 분할 확대 / 되돌리기 |
| <kbd>⇧⌘F</kbd> | 전체 창 / 되돌리기 |
| <kbd>⌥⇧⌘←</kbd> <kbd>⌥⇧⌘→</kbd> <kbd>⌥⇧⌘↑</kbd> <kbd>⌥⇧⌘↓</kbd> | 분할 크기 조절 |
| <kbd>⌘W</kbd> | 세션 닫기(빈 화면이면 화면 닫기) |

배치는 저장돼서 앱을 다시 열면 돌아와요. [복원과 전력](/ko/docs/workspace/restore-and-power/)을 보세요.
