명령 팔레트는 Aquila에서 가장 빨리 움직이는 방법이에요. <kbd>⌘K</kbd>를 누르고 몇 글자 입력한 뒤 Enter를 눌러요.

<Shot id="palette" caption="팔레트: 기다리는 세션이 맨 위, 그다음 프로젝트, 그다음 명령." />

## 열고 쓰기

| 키 | 동작 |
|---|---|
| <kbd>⌘K</kbd> | 팔레트 열기 / 닫기 |
| <kbd>↑</kbd> <kbd>↓</kbd> (또는 <kbd>⌃N</kbd> <kbd>⌃P</kbd>) | 목록에서 이동 |
| <kbd>↩</kbd> | 이동하거나 실행 |
| <kbd>Esc</kbd> | 닫기(바깥을 클릭해도 닫혀요) |

항목을 고르면 팔레트가 닫히고, 키보드 입력은 바로 그 터미널로 가요.

## 목록에 무엇이 있나요

아무것도 입력하지 않으면 이 순서로 보여요.

1. **열린 세션**. 급한 순서예요: 입력 필요, 오류, 완료, 작업 중, 멈춤, 대기. 그래서 나를 기다리는 세션이 늘 맨
   위에 있어요. <kbd>⌘K</kbd> <kbd>↩</kbd>면 바로 그 세션으로 가요.
2. **프로젝트**. 사이드바 순서대로, 상태 점과 함께 보여요.
3. 지금 쓸 수 있는 **명령**. 단축키가 있으면 옆에 보여요.
4. 지금 프로젝트의 **워크트리**. 각각에서 Claude, Codex, 셸을 열 수 있어요.

지금 쓸 수 없는 명령은 보이지 않아요. 프로젝트를 고르지 않았으면 "열기" 명령이 없고, 세션이 없으면 **세션 닫기**가
없어요.

## 찾기

이름 어디든 일부를 입력해요. 글자가 순서대로만 있으면 붙어 있지 않아도 되고, 대소문자도 상관없어요. 예를 들어
영어 UI에서 `spr`은 **Split right**를 찾아요. 단어 첫 글자나 이어진 글자가 맞으면 더 위로 오고, 맞은 글자는
강조돼요.

프로젝트는 그룹과 폴더 경로로도 찾아지고, 이름으로 맞은 것보다 아래에 와요.

<Aside type="tip">
  한글 입력 상태에서도 잘 돼요. 글자를 조합하는 동안에는 키를 무시해서, Enter가 미리 실행되지 않아요.
</Aside>

## 실행할 수 있는 것

자주 쓰는 명령을 용도별로 모았어요. 이름은 앱에 보이는 그대로예요.

| 용도 | 명령 |
|---|---|
| 세션 | **Claude 열기**, **Codex 열기**, **셸 열기**, **워크트리에서 열기**, **세션 닫기**, **세션 이름 바꾸기**, **세션 기록** |
| 알림 | **다음 대기 세션으로**, **다음 리뷰로** |
| 화면 | **오른쪽으로 분할**, **아래로 분할**, **분할 확대 / 되돌리기**, **전체 창 / 되돌리기** |
| 패널 | **변경사항 보기**, **미리보기 보기**, **실행 패널 보기** |
| 프로젝트 | **프로젝트 추가**, **원격 서버 추가…**, **프로젝트 설정…**, **Finder에서 열기**(또는 정한 에디터) |
| 터미널 | **마지막 응답 복사**, **URL·경로 고르기**, **터미널에서 찾기** |
| 앱 | **English로 바꾸기**, **전역 단축키…**, **시작 점검**, **가이드**, **새로운 기능** |

노트와 확장 기능 명령도 있어요. [노트](/ko/docs/notes/graph/) 문서를 보세요.

명령마다 연결된 단축키는 [단축키](/ko/docs/reference/shortcuts/)에 있어요.
