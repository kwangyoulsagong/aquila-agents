## 다시 열면 그대로

앱을 종료하든, Mac을 재시동하든, 앱이 갑자기 꺼지든, 다시 열면 작업 공간이 돌아와요.

<Shot id="restore" caption="다시 연 뒤: 같은 탭과 분할, 이어서 열린 대화." />

돌아오는 것:

| | 다시 열면 |
|---|---|
| **탭** | 모든 탭이 같은 순서로, 이름과 Claude 계정도 그대로 돌아와요. |
| **분할 배치** | 같은 화면 배치, 같은 화면에 포커스. |
| **Claude** | 같은 대화를 이어서 열어요(`claude --resume`). `/clear` 뒤의 대화도 따라가요. |
| **Codex** | 같은 대화를 이어서 열어요(`codex resume`). |
| **셸** | 같은 폴더에서 새 셸이 열리고, 위에 이전 출력이 흐리게 **이전 출력 · 시간 · 읽기 전용** 줄 아래 보여요. |
| **워크트리 탭** | 그 워크트리에서 다시 열려요. |

저장된 상태는 바뀔 때마다 다시 써서, 앱이 갑자기 꺼져도 잃는 게 없어요.

### 보이는 것만 바로 시작해요

빨리 열리도록 보이는 화면의 세션만 바로 시작해요. 나머지 탭은 목록에만 있다가, 처음 화면에 보일 때 시작해요.

### 알아 둘 것

- 메시지를 한 번도 보내지 않은 Claude 탭은 아직 대화가 없어서 새 Claude 세션으로 열려요.
- 대화를 이어서 열 수 없으면 탭에 이전 출력과 함께 **세션을 이어서 열지 못했어요**가 뜨고, 그 폴더의 셸로
  돌아가요. 대화는 [세션 기록](/ko/docs/agents/session-history/)에서 찾을 수 있어요.
- 셸에서 직접 돌리던 명령(dev 서버, 워처)은 다시 시작하지 않아요. [실행 패널](/ko/docs/agents/run/)의 명령은 다시
  시작해요.
- 제거한 프로젝트의 탭, 폴더가 없어진 워크트리 탭은 빠져요. 탭의 Claude 계정이 없어졌으면 프로젝트 계정을 써요.

<Aside type="note">
  상태는 `~/.aquila/state.json`에, 셸 출력 스냅숏은 `~/.aquila/scrollback/`에 저장돼요. 탭을 닫으면 그 스냅숏도
  지워져요.
</Aside>

## 배터리 절약

Mac이 **배터리로 동작**하거나, **스로틀링** 중이거나(CPU 속도 제한), **발열**이 심하면 Aquila가 알아서 가벼운
모드로 바뀌어요. 따로 설정은 없고, 그 상태가 끝나면 바로 돌아와요.

배터리 절약 중에는:

- 반복 애니메이션이 멈춰요. 작업 중 점은 깜박이는 대신 반만 채운 원으로, 입력 필요 점의 테두리 빛도 멈춰요.
- 터미널 커서가 깜박이지 않아요.
- 보이지 않는 세션은 화면을 덜 자주 갱신해요(1초에 5번 대신 1번).
- 변경 패널, Claude 계정 상태 같은 백그라운드 확인을 덜 자주 해요.
- 가이드 영상은 정지 화면으로 보여요.
- 노트 소스 색인, 자동 링크 제안 같은 백그라운드 노트 작업 일부를 멈춰요.

화면에 보이는 터미널은 여전히 매 프레임 갱신되고, <kbd>⌃C</kbd>도 바로 먹혀요.

<Shot id="power" caption="배터리 절약: 멈춘 점, 깜박이지 않는 커서, 조용해진 백그라운드." />

## 언어 바꾸기

Aquila 화면은 한국어와 영어를 지원해요.

사이드바 왼쪽 아래 **⚙ 설정**을 누르고 **언어**에서 **한국어**나 **English**를 골라요. 또는 <kbd>⌘K</kbd>를 누르고
**English로 바꾸기**를 실행해요(영어 화면에서는 **Switch to 한국어**).

메뉴 막대까지 앱 전체가 바로 바뀌어요. 세션은 계속 돌아가고, CLI 자체의 언어는 바뀌지 않아요.

<Shot id="language" caption="⚙ 설정 → 언어." />

같은 **⚙ 설정** 메뉴에는 **화면 모드**(시스템 설정 따르기, 라이트, 다크), **완료 시 알림**, **전역 단축키…**,
**설정 파일 열기**도 있어요.
