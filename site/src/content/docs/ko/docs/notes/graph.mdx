노트 그래프는 프로젝트 안의 Markdown 파일(기획서, 회의록, 체크리스트, README)을 모아 서로 어떻게 링크되는지,
에이전트가 다룬 세션·할 일·파일과 어떻게 이어지는지 보여줘요.

<Shot id="graph" caption="이번 주, 묶음으로 보는 전체 지도, 연 노트가 가운데 오는 주변 보기." />

## 그래프 열기

- <kbd>⇧⌘N</kbd>을 누르거나 탭 바의 **그래프**를 눌러요. 오른쪽에 패널로 열려요.
- 패널 머리의 **⤢**를 누르면 창 전체로 커져요(**그래프만 크게 보기**). 한 번 더 누르면 돌아와요.

## 설정할 게 없어요

사이드바에 있는 로컬 프로젝트는 모두 저절로 색인돼요. 레포마다 노트를 어디에 두든 `.md` 파일을 다 찾아서, 폴더 구조를
맞출 필요가 없어요. 숨김 폴더, 빌드 폴더, 프로젝트 `.gitignore`에 적힌 것은 빼요.

- 색인은 뒤에서 돌고, 바뀐 파일만 다시 읽어요.
- 파일은 색인하려고 읽기만 해요. 그래프가 파일을 고치는 일은 없어요.
- 그래프나 다른 노트 기능을 처음 열기 전에는 아무것도 돌지 않아요.

### 프로젝트 밖 폴더 더하기

프로젝트에 없는 노트(회의록 폴더, 개인 위키)도 넣으려면 **⚙ 설정 ▸ 노트 소스…**에서 **폴더 추가…**를 눌러요. 같은
창에서 프로젝트 폴더를 **끄기**로 뺄 수 있고, 소스마다 노트가 몇 개인지도 보여요. **빼기**는 색인에서만 빼고 파일은
그대로 둬요.

<Aside type="note">
  배터리 절약 중에는 아주 큰 폴더의 첫 색인이 멈춰 있다가 **지금 색인**을 누르면 시작해요.
</Aside>

## 프로젝트 고르기

패널 맨 위 **프로젝트** 메뉴로 볼 범위를 한 프로젝트로 좁혀요. 기본은 **현재 프로젝트**, 즉 앞에 있는 탭의
프로젝트라서 탭을 옮기면 그래프도 따라와요. 다른 곳을 보려면 **모든 프로젝트**나 특정 프로젝트를 골라요.

## 이번 주

**이번 주**는 최근 7일 동안 바뀐 노트·세션·파일을 최신순으로, 날짜별(오늘, 어제, 그 전 날짜)로 보여줘요.

- 체크아웃이나 풀처럼 한꺼번에 바뀐 파일은 한 줄로 접히고, 눌러서 펼쳐요.
- 줄에 마우스를 올리고 **주변**을 누르면 그 항목을 그래프 가운데에 놓아요.
- **지금 탭**을 켜면 앞에 있는 탭의 대화와 그 대화가 바꾼 파일·다룬 노트만 남아요(기간 상관없이).

## 전체 지도

**전체 지도**는 프로젝트의 모양을 묶음 원으로 보여줘요. 원 하나가 노트 묶음 하나예요(폴더, 코드·파일·세션 같은 종류,
내가 만든 묶음).

| 보이는 것 | 뜻 |
|---|---|
| 원 크기 | 묶음 안의 노트 수 |
| 선 굵기 | 두 묶음 사이 링크 수 |
| 원 아래 숫자 | 이번 주에 바뀐 노트 |

### 안으로 들어가기

원을 누르면 하위 폴더로 내려가요. 묶음이 충분히 작아지면 노트 하나하나가 점으로 펼쳐져요. 위로 돌아갈 때는 **뒤로**나
지도 위의 경로를 눌러요.

### 여러 묶음 같이 보기

<kbd>⌘</kbd>를 누른 채 원 여러 개를 클릭하고 **고른 N개 같이 보기**를 눌러요. 이름이 같은 폴더끼리 합쳐져요. 예를
들어 두 레포의 `requirements` 폴더가 한 묶음이 돼요.

### 내 묶음 만들기

**묶음 편집**에서 이름과 `path:specs`, `tag:auth`, `kind:session` 같은 검색식으로 묶음을 더해요. 노트가 여러 묶음에
맞으면 목록에서 위에 있는 묶음이 먼저예요.

### 질문

**질문** 칩을 누르면 그 질문에 해당하는 점만 밝아지고 나머지는 흐려져요. **할 일**, **연결 없는 노트**, **최근 7일
세션**, **열린 세션**, **작업 후 그대로인 노트**(마지막으로 고친 뒤 그 노트를 다룬 세션이 있었던 노트), 그리고 요구사항
ID용 **작업 없는 ID**, **모르는 ID · 중복 ID** 같은 것들이에요. 칩은 해당하는 게 있을 때만 보여요.

## 주변

**주변**은 노트 하나를 가운데 두고 이어진 것을 펼쳐 보여줘요.

- **왼쪽:** 연결된 노트(태그, 사람, 결정 포함), 그 바깥에 한 단계 더.
- **오른쪽:** 세션·할 일·바뀐 파일, 그 바깥에 한 단계 더.

**에디터 따라가기**를 켜 두면 가운데는 늘 에디터에서 연 노트예요. 끄면 다른 노트를 고치는 동안에도 지금 노트에
고정돼요.

| 하고 싶은 것 | 방법 |
|---|---|
| 다른 항목을 가운데로 | 클릭 |
| 돌아가기 | **뒤로** 또는 <kbd>⌫</kbd> |
| 항목 사이 이동 | 화살표 키 |
| 고른 항목을 가운데로 | <kbd>↩</kbd> |
| 에디터에서 열기 | 더블클릭, <kbd>⌘</kbd>클릭, <kbd>⌘↩</kbd> |

칸마다 가장 관련 깊은 몇 개만 보이고, 나머지는 **+N개 더**로 접혀요.

### 선 모양

| 선 | 뜻 |
|---|---|
| 실선 | 직접 적은 링크: `[[링크]]`, Markdown 링크, 태그, frontmatter 값 |
| 파선 | 본문에서 찾은 연결: 같은 ID, 다른 노트 제목 언급, 코드 이름, 같은 URL |
| 점선 | 제안: 두 노트가 특징적인 단어를 함께 써요 |

### 제안된 연결

노트를 고르고 아래 카드의 **제안된 연결**을 펼쳐요. 제안마다:

- **연결**은 파일은 건드리지 않고 그래프에 실선으로 남겨요.
- **`[[링크]]` 넣기**는 노트 끝에 `[[이름]]`도 적어요.
- **관계없음**은 다시 제안하지 않아요.

같은 종류의 연결을 세 번 받아들이면 늘 연결하는 규칙을 제안해요. 규칙은 **⚙ 설정 ▸ 링크 제안…**에서 관리해요.

## 에디터에서 노트 열기

- 그래프에서 노트를 <kbd>⌘</kbd>클릭하거나 더블클릭해요.
- 어디서든 <kbd>⌘O</kbd>를 누르고 노트 이름 일부를 입력해요.
- 노트를 고르고 카드의 **열기**를 눌러요.

에디터에서 할 수 있는 일은 [노트 에디터](/ko/docs/notes/editor/)를 보세요.

## 입력하면서 노트 링크하기

에디터에서 `[[`를 치면 노트 이름 목록이 떠요. 하나를 고르면 색인이 알아보는 링크로 넣어줘요.

<Aside type="tip">
  노트나 할 일에서 **Claude로 처리**를 누르면 그 노트가 있는 프로젝트에 Claude 탭이 열리고 노트가 `@경로`로 붙어요.
  Enter를 누르기 전에는 아무것도 보내지 않아요.
</Aside>
