노트 에디터는 노트 소스 안의 `.md` 파일을 세션 바로 옆에서 열어요. 화면은 문서처럼 보이지만 디스크의 파일은 그대로
Markdown이에요. 내가 바꾼 글자만 저장하고, 줄 끝 문자나 줄 끝 공백 같은 나머지는 원래대로 둬요.

## 노트 열기

- <kbd>⌘O</kbd> — 이름으로 노트를 찾아요.
- <kbd>⇧⌘O</kbd> — 노트 탐색기를 열고 둘러봐요.
- [그래프](/ko/docs/notes/graph/)에서 노트를 <kbd>⌘</kbd>클릭하거나 더블클릭해요.
- 다른 노트의 `[[링크]]`나 백링크를 눌러요.

에디터는 오른쪽 패널로 열려요. 머리의 **⤢**는 창 전체로 키우고(**노트만 크게 보기**), **↗**는 파일을 기본 앱으로
열어요.

## 노트가 보이는 모습

에디터는 노트를 문서처럼 보여줘요. 가운데 단, 제목과 폴더·수정일, 그리고 콜아웃·코드(언어 표시와 복사 버튼)·표가
카드로 보여요. 체크박스는 진짜 체크박스로, `[[링크]]`는 알약 모양으로 그려요.

Markdown 기호(`#`, `**`, 링크 주소)는 지금 고치는 줄에서만 보이고 나머지에서는 숨어요. 표는 안을 클릭하면 칸을 고칠
수 있고, <kbd>Tab</kbd>·<kbd>⇧Tab</kbd>으로 칸을 옮기고 <kbd>↩</kbd>로 줄을 더해요.

본문 옆 **목차와 링크** 칸에는 노트의 제목들(**목차**), 이 노트를 링크한 노트, 링크 없이 이 노트 제목을 언급한 노트가
보여요.

## 저장

따로 저장할 필요가 없어요. 에디터를 벗어날 때, 입력을 멈추고 1초 뒤, 그리고 <kbd>⌘S</kbd>를 누를 때 저장해요. 다른
노트로 옮기거나 패널을 닫을 때도 먼저 저장해요.

저장 안 한 수정이 있는데 디스크의 파일이 바뀌면(예: 에이전트가 고쳤을 때) 배너가 떠서 **비교**, **내 것 유지**(내
것으로 덮어쓰기), **다시 불러오기** 중에 고르게 해요. 저장 안 한 수정이 없으면 그 자리에서 조용히 다시 불러와요.

<Aside type="note">
  UTF-8이 아닌 파일은 저장하면 바이트가 바뀌니까 읽기 전용으로 열려요. 2MB가 넘는 파일은 앞부분만 읽기 전용으로
  보여요.
</Aside>

노트에 이미지를 붙여 넣으면 노트 옆 `attachments/<노트>-<시각>.<확장자>`로 저장되고 링크가 들어가요.

## 블록

<Shot id="blocks" caption="⋮⋮ 손잡이로 블록을 끌어 옮기거나 / 메뉴로 블록을 넣어요." />

노트의 문단·목록·제목 하나하나가 블록이에요.

- **마우스로 옮기기:** 줄에 마우스를 올리면 왼쪽에 **⋮⋮** 손잡이가 떠요. 끌어서 블록을 옮겨요.
- **블록 메뉴:** 손잡이를 누르면 **바꾸기**, **복제**, **삭제**, **Markdown으로 복사**가 나와요.
- **키보드로 옮기기:** <kbd>⌥⇧↑</kbd> / <kbd>⌥⇧↓</kbd>로 커서가 있는 블록을 위·아래로 옮겨요.

번호 목록은 옮기면 번호가 다시 매겨지고, 파일은 그대로 Markdown이에요.

### / 메뉴

빈 줄에서 <kbd>/</kbd>를 치면 블록을 골라 넣어요.

- **제목 1**, **제목 2**, **제목 3**
- **글머리 목록**, **번호 목록**, **할 일**
- **인용**, **콜아웃**, **코드 블록**, **표**, **구분선**
- **노트 링크**

계속 입력하면 걸러져요. 한국어로도 찾아요(`/할` → **할 일**). 한글을 조합하는 중에는 메뉴가 열리지 않아요.

## 읽기 모드

<kbd>⌘E</kbd>를 누르거나 머리의 **읽기**를 누르면 Markdown 기호가 모두 숨고 편집이 잠겨요. 링크와 체크박스는 그대로
눌러져요. <kbd>⌘E</kbd>를 한 번 더 누르면 편집으로 돌아와요.

## 노트 탐색기

에디터 왼쪽 **파일 목록** 칸은 지금 탭 프로젝트의 노트를 폴더 트리로 보여줘요. 에디터 머리의 **▤**, <kbd>⇧⌘O</kbd>,
또는 <kbd>⌘K</kbd>의 **노트 탐색기**로 열어요.

<Shot id="explorer" caption="파일 목록: 노트를 트리로 보고, 새 노트에는 다음 ID를 제안해요." />

### 노트 찾기

위쪽 필터에 입력하면 경로·제목·ID로 찾아요(한국어도 돼요). 맞는 폴더가 펼쳐지고, <kbd>↩</kbd>를 누르면 가장 잘
맞는 노트가 열려요. 트리 맨 위에는 **고정됨**과 **최근** 노트가 있어요.

### 만들기, 이름 바꾸기, 옮기기

노트나 폴더를 우클릭하거나, 마우스를 올리면 나오는 버튼을 쓰거나, 트리에 포커스가 있을 때 키를 눌러요.

| 하고 싶은 것 | 방법 |
|---|---|
| **새 노트** | <kbd>⌘N</kbd>. 형제 노트가 같은 ID를 쓰면(`FE-REQ-029`, `FE-REQ-030`) 다음 번호 `FE-REQ-031`을 제안해요 |
| **새 폴더** | 우클릭 메뉴나 마우스 오버 버튼 |
| **이름 바꾸기** | <kbd>F2</kbd> |
| 옮기기 | 폴더 위로 끌어다 놓거나, **이동…**에서 폴더를 찾아요 |
| **고정** / **고정 해제** | 우클릭 메뉴 |
| **Finder에서 보기**, **경로 복사** | 우클릭 메뉴 |
| **휴지통으로** | <kbd>⌘⌫</kbd>. 항상 먼저 물어봐요 |
| 되돌리기 | <kbd>⌘Z</kbd> |

<kbd>⌘</kbd>클릭이나 <kbd>⇧</kbd>클릭으로 여러 노트를 골라 한꺼번에 옮기거나 버려요. 이미 있는 이름은 거절해요.
탐색기는 파일을 덮어쓰지 않아요.

### 링크는 그대로 이어져요

이름을 바꾸거나 옮기면 **N개 노트의 링크를 고칠까요?**라고 물으며 해당 노트를 보여줘요. **고치기**를 누르면 옮긴
것을 가리키는 링크 부분(`[[이름]]`, `[[이름#제목|별칭]]`, 상대 경로 `[글](경로.md)` 링크)만 바꾸고 나머지 글자는
그대로 둬요. 코드 블록은 건드리지 않아요. 매번 묻지 않게 하려면 **항상**이나 **안 함**을 고르거나, 나중에 필터 옆 보기
메뉴의 **옮긴 뒤 링크 고치기**에서 바꿔요.

### 되돌리기

트리에서 <kbd>⌘Z</kbd>를 누르면 옮기기, 이름 바꾸기, 새 폴더(아직 비어 있을 때), 새 노트(아직 고치지 않았을 때)를
되돌려요.

<Aside type="caution">
  **휴지통으로**는 <kbd>⌘Z</kbd>로 되돌릴 수 없어요. Finder의 휴지통에서 되살려요.
</Aside>

### 보기 옵션

필터 옆 보기 메뉴에는 **상태별 보기**(노트의 `status:` 속성에 따라 todo, in progress, review, done 등으로 나눠 보기),
**이름순**·**수정일순**·**생성일순** 정렬, 폴더 노트(`index.md`·`README.md`를 폴더 이름으로 열기), 하위 폴더 하나뿐인
폴더를 한 줄로 보기가 있어요.

## 에디터 키

| 키 | 동작 |
|---|---|
| <kbd>⌥⇧↑</kbd> / <kbd>⌥⇧↓</kbd> | 블록 위·아래로 옮기기 |
| <kbd>/</kbd> | 블록 메뉴 (빈 줄에서) |
| <kbd>⌘E</kbd> | 읽기 모드 |
| <kbd>⌘S</kbd> | 바로 저장 |
| <kbd>⌘F</kbd> | 노트에서 찾기 |
| <kbd>⌘Z</kbd> / <kbd>⇧⌘Z</kbd> | 되돌리기 / 다시 하기 |
| `[[` | 노트 이름 제안 |

<Aside type="tip">
  노트 에디터 안에서는 <kbd>⌘W</kbd>가 세션을 닫지 않고, <kbd>⌘F</kbd>·<kbd>⌘D</kbd>는 터미널·화면 분할 대신
  에디터 몫(찾기, 다음 일치 항목 선택)이에요. [단축키](/ko/docs/reference/shortcuts/)를 보세요.
</Aside>
