기획 문서나 긴 메일, Figma 링크를 받았는데 시작하기 전에 무슨 내용인지부터 알고 싶을 때가 있죠. **이게 뭐야?**는 그걸
읽고 제품·기능·의도·요점·열린 질문을 짧게 정리해 주고, 이미 가진 관련 노트도 찾아줘요.

## 열기

- <kbd>⌘K</kbd> → **이게 뭐야?**
- 그래프나 노트 에디터 머리의 **이게 뭐야?** 버튼.
- 파일을 끌어다 놓기.

## 넣을 수 있는 것

| 입력 | 방법 | 참고 |
|---|---|---|
| 텍스트, Markdown | 붙여 넣거나 `.md`·`.txt` 파일을 놓기 | 5MB까지 |
| 메일 | 붙여 넣거나 `.eml` 파일을 놓기 | 메일 헤더는 제목·보낸 사람·날짜만 남겨요 |
| HTML 페이지 | `.html` 파일을 놓기 | 텍스트로 읽어요 |
| PDF | `.pdf` 파일을 놓기 | 20MB까지, 내 Mac에서 읽어요 |
| Figma 링크 | `figma.com` 링크를 붙여 넣기 | 아래 Figma 링크를 보세요 |

끌어다 놓는 대신 **파일 선택…**을 써도 돼요.

### PDF와 OCR

PDF는 내 Mac에서 읽어요. 글자 층이 없는 스캔 PDF는 macOS에 들어 있는 글자 인식(OCR)으로 한국어·영어를 앞 30쪽까지
읽어요. 따로 설치할 것도 없고, 이걸 위해 어딘가로 올리지도 않아요. 미리보기에 **OCR로 읽음**이 뜨고, 쪽이 잘렸으면
알려줘요. 암호가 걸린 PDF는 읽을 수 없어요. 열어서 내용을 복사해 붙여 넣어요.

### Figma 링크

[Figma가 연결돼 있으면](/ko/docs/agents/figma-designer/) Claude가 Figma에서 파일을 읽어요(읽기만 해요). 연결돼 있지
않으면 링크와 함께 붙여 넣은 글만 보내요.

## 보낼 내용 확인하기

<Steps>

1. 놓거나 붙여 넣은 뒤 **보낼 내용 보기**를 열어요. Claude에게 갈 글이 그대로 보여요. 최대 2만 자이고, 더 길면
   잘린다고 알려줘요("앞 N자만 보내요").

2. 경고 줄을 읽어요. 어느 Claude 계정으로 보내는지 적혀 있어요. 비밀번호나 개인 정보가 없는지 확인해요.

3. **모델**을 골라요. 기본은 **Haiku (빠름)**, 자세히 보려면 **Sonnet (자세히)**.

4. **Claude에게 묻기**를 눌러요.

</Steps>

<Aside type="caution">
  Claude는 **Claude에게 묻기를 누를 때 한 번만** 실행되고, 내 Claude 계정과 사용량을 써요. 놓거나 붙여 넣기만 해서는
  아무것도 보내지 않아요. 도구 없이 빈 임시 폴더에서 실행돼서 레포를 읽을 수 없어요.
</Aside>

결과는 이번 세션 동안 남아 있어요. 같은 내용을 다시 물으면 Claude를 또 부르지 않고 **이번 세션에서 이미 읽은 결과예요**를
보여줘요. 입력을 바꾸면 아직 돌고 있던 요청은 취소돼요.

## 요약 카드

**요약 카드**는 정해진 칸으로 나와요.

- **제품**, **기능**
- **의도** — 쓴 사람이 원하는 것
- **핵심**
- **열린 질문** — 문서가 답하지 않은 것
- **용어·ID** — 문서에 나오는 이름과 ID

Claude의 답이 이 형식으로 오지 않으면 **Claude의 답** 아래에 그대로 보여줘요.

### 관련 노트

**관련 노트**에는 노트 소스 중에서 입력과 같은 ID나 특징적인 단어를 함께 쓰는 노트가 나와요. Claude 없이 내 Mac에서
찾아요. 관련 노트가 없다고 나오면 [노트 소스](/ko/docs/notes/graph/)를 켜 보세요.

## 노트로 저장

**노트로 저장**을 누르고 **저장할 곳**과 **제목**을 정해요. frontmatter에 `type: brief`가 붙은 Markdown 노트가
만들어져서, [표 보기](/ko/docs/notes/properties-table/)에서 요약만 골라 보기 쉬워요. **열기**를 누르면 바로 가요.
