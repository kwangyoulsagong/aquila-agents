기획서에 `FE-REQ-030`, `API-12`, `DB-7` 같은 ID를 쓴다면, Aquila가 모든 노트에서 알아보고 에디터에서 밑줄을 그어요.
어느 노트가 ID를 정의했고 어떤 노트·세션·파일이 그 ID를 참조하는지도 따라가요. ID 형식은 정해져 있지 않고, 노트를
보고 접두어를 익혀요.

## 무엇이 ID인가요

ID는 대문자 접두어, 하이픈, 숫자로 돼 있어요: `REQ-12`, `FE-REQ-030`. 접두어는 여러 마디여도 돼요.

어떤 노트가 그 접두어로 ID를 정의했거나, 그 접두어가 ID 두 개 이상 또는 노트 두 개 이상에 나오면 그때부터 따라가요.
그래서 어쩌다 한 번 나온 `UTF-8` 같은 건 요구사항이 되지 않아요.

### ID를 정의하는 곳

노트가 ID를 **정의**하는 경우는:

- frontmatter에 `id: FE-REQ-030`이 있거나,
- 파일 이름이나 제목이 ID로 시작할 때예요(`FE-REQ-030-login.md`, `# FE-REQ-030 로그인`).

그 밖에 ID가 나오는 곳은 모두 **언급**이에요.

## ID 상태

ID 상태에 따라 밑줄이 다르게 보여요.

| 상태 | 뜻 |
|---|---|
| 정의됨 | 딱 한 노트가 정의해요 |
| 중복 | 두 노트 이상이 정의해요 — 대개 복사·붙여넣기 실수예요 |
| 모르는 ID | 정의한 노트가 없지만 같은 접두어의 다른 ID는 정의돼 있어요 — 오타나 지운 기획서일 때가 많아요 |
| 느슨한 ID | 색인이 아는 접두어지만 아무 노트도 정의하지 않아요(다른 도구의 티켓 번호 등) |

## 카드

에디터에서 ID에 마우스를 올리면 카드가 떠요.

- 정의한 노트(모르는 ID나 중복 ID면 경고와 함께, 같은 ID를 정의한 다른 노트),
- 그 노트의 `status` 속성,
- 참조 수: **노트 N개 · 세션 M개 · 파일 K개에서 참조**.

ID를 <kbd>⌘</kbd>클릭하면 정의한 노트가 열려요.

## 참조된 곳

ID를 정의한 노트를 열면 옆 칸에 **참조된 곳**이 보여요.

| 항목 | 보이는 것 | 누르면 |
|---|---|---|
| **노트** | 그 ID를 언급한 노트 | 노트가 열려요 |
| **세션** | 그 ID를 다룬 세션 — 정의한 노트를 다뤘거나 제목에 ID가 있는 세션 | 열려 있으면 그 탭으로, 아니면 이어서 열어요 |
| **바뀐 파일** | 그 세션들이 바꾼 파일 | Finder에서 보여줘요 |

노트에 할 일이 있으면 **체크리스트** 막대가 몇 개 끝났는지 보여줘요.

### 언급을 링크로 바꾸기

링크 없이 이름만 적은 노트 옆의 **링크로 바꾸기**를 누르면 그 노트에서 처음 나오는 언급을 `[[이름]]`으로 바꿔요.
먼저 **"…" 파일을 고칠까요?**라고 묻고, 그 노트의 해당 글자만 바꿔요. 코드나 이미 있는 링크 안의 언급은 건드리지
않아요.

## 그래프에서 빈틈 찾기

[그래프](/ko/docs/notes/graph/)의 전체 지도에서 **질문** 칩 두 개가 요구사항을 점검하는 데 도움이 돼요.

- **작업 없는 ID** — ID를 정의했는데 아직 그걸 다룬 세션이 없는 노트.
- **모르는 ID · 중복 ID** — 두 노트가 같은 ID를 정의했거나, 정의한 노트가 없는 ID를 언급한 노트.

같은 ID를 쓰는 노트끼리는 서로 링크하지 않아도 파선으로 이어져요.

  노트 탐색기에서 `FE-REQ-029`, `FE-REQ-030` 옆에 새 노트를 만들면 이름으로 `FE-REQ-031`을 제안해요. 자세한 건
  [노트 에디터](/ko/docs/notes/editor/)를 보세요.
</Aside>
