노트는 흔히 YAML frontmatter(`status`, `owner`, 날짜, 태그)로 시작해요. Aquila는 이걸 노트 맨 위에 고칠 수 있는 속성
줄로 보여주고, 폴더의 노트를 그 속성으로 만든 표로 모아 보여줘요.

<Shot id="properties" caption="속성 줄로 보이는 frontmatter, 그리고 같은 노트를 표 보기로." />

## 속성

frontmatter가 있는 노트는 본문 위에 키들이 **속성**으로 보여요.

```md
---
status: in progress
owner: mina
due: 2026-12-05
tags: [auth, login]
---
```

값마다 알맞은 입력칸이 붙어요.

| 값 | 입력칸 |
|---|---|
| 일반 텍스트 | 텍스트 칸 |
| `YYYY-MM-DD` | 날짜 |
| 목록 | 칩 — **추가…**로 더하고 ×로 빼요 |
| 폴더 설정에서 선택지로 정한 속성 | 정한 선택지 중에서 고르기 |

### 고치기, 더하기, 지우기

- 값을 눌러서 바꿔요.
- **+ 속성 추가**로 새 줄을 더해요. **이름**과 **값**을 입력해요.
- 줄의 지우기 버튼으로 속성을 지워요.

바꾼 frontmatter 줄만 다시 쓰고, 파일의 나머지 바이트는 그대로 둬요.

<Aside type="note">
  이미 있는 이름이나 YAML 키로 쓸 수 없는 이름은 짧은 안내와 함께 거절해요.
</Aside>

## 표 보기

표 보기는 노트 소스 하나의 노트를 줄로, 속성을 열로 보여줘요.

<kbd>⌘K</kbd> → **표 보기**로 열거나, 노트 속성 칸의 **표 보기** 버튼("이 폴더의 노트를 표로 봐요")을 눌러요.

### 무엇을 볼지 고르기

- **소스** — 어느 노트 폴더를 볼지.
- **열** — 열을 고르고 순서를 정해요. **제목**, **폴더**, **수정**은 늘 있고, 노트들이 쓰는 속성도 모두 고를 수 있어요.
  **기본 열로**를 누르면 처음대로 돌아가요.
- **정렬** — 열 머리를 눌러요.

열·정렬·묶기는 이 Mac에서 소스마다 기억해요.

### 필터

- 검색 칸은 제목·경로·값에서 찾아요.
- **폴더**로 한 폴더만 봐요(기본은 **모든 폴더**).
- **속성 필터**로 속성과 **값**(또는 **모든 값**)을 골라요.
- 상태 칩(**status별 개수**)은 값마다 노트가 몇 개인지 보여주고, 누르면 그 값으로 걸러요.

### 묶기

**묶기**는 줄을 제목 아래로 모아요. **폴더로 묶기**나 아무 속성으로 묶을 수 있어요(예: **status(으)로 묶기**).
**묶지 않기**로 꺼요.

### 열기와 고치기

- 제목을 누르면 에디터에서 노트가 열려요.
- 칸을 더블클릭하거나 칸에서 <kbd>↩</kbd>를 누르면 그 자리에서 값을 고쳐요.

바뀐 값은 속성 칸에서 고칠 때와 똑같이 그 노트의 frontmatter 한 줄만 바꿔요.

<Aside type="caution">
  표를 불러온 뒤 디스크의 파일이 바뀌었으면(에이전트나 다른 앱이 고쳤으면) "그사이 파일이 바뀌어서 저장하지 않았어요"
  라며 거절해요. 표를 다시 열고 고쳐요.
</Aside>
