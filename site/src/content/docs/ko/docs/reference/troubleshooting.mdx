## macOS가 앱을 열어 주지 않아요

아직 서명·공증 전이라 처음 열 때 "확인되지 않은 개발자"라며 막혀요. 아래 중 하나를 한 번만 하면 돼요.

- Finder에서 앱을 **우클릭** → **열기** → **열기**.
- 또는 터미널에서:

  ```sh
  xattr -dr com.apple.quarantine "/Applications/Aquila Agents.app"
  ```

[설치](/ko/docs/start/install/)를 보세요.

## Claude나 Codex를 못 찾아요

Aquila는 Mac에 설치된 CLI를 실행해요. **시작 점검**에서 무엇을 찾았는지 보여줘요.

<Steps>

1. <kbd>⌘K</kbd> → **시작 점검**으로 열어요.

2. 첫 줄을 확인해요. **셸 PATH 불러옴**이면 로그인 셸이 만드는 `PATH`(`~/.zshrc`, fnm, nvm 등이 더한 것 포함)를 읽은
   거예요. **셸 PATH를 못 읽었어요**면 시스템 `PATH`로 찾고 있어요.

3. **찾을 수 없어요**로 나온 CLI에는 설치 명령이 보여요. 복사해서 터미널에서 실행한 뒤 **다시 확인**을 눌러요. 확인하기
   전에 셸 `PATH`를 다시 읽어요.

4. 흔치 않은 곳에 설치했다면 **경로 지정…**을 눌러 실행 파일을 골라요. `--version`이 실행되는 파일만 받아들이고, 그
   뒤로 새 세션은 그 파일을 그대로 써요.

</Steps>

<Aside type="note">
  도구는 `PATH`에서만 찾고 셸 별칭(alias)은 보지 않아요. 셸에서 `claude`가 별칭이라면 **경로 지정…**으로 실제 파일을
  골라요. `git`은 변경사항 패널과 워크트리에 필요해요. 새 Mac이라면 먼저 Apple 명령행 도구를 설치해요
  (`xcode-select --install`).
</Aside>

세션은 프로젝트 폴더에서 로그인·대화형 셸로 시작해요. 그래서 터미널에서 쓰던 `PATH`, 버전 관리자, 별칭이 모든 탭에서
그대로 적용돼요.

## CLI가 로그인하라고 해요

처음엔 그게 정상이에요. Claude는 `/login`을, Codex는 로그인을 요청해요. 탭 안에서 로그인하면 돼요. Aquila는 토큰을
보거나 저장하지 않아요.

두 번째 Claude 계정은 계정 전환 옆 **설정** 버튼을 써요. [Claude 계정](/ko/docs/agents/claude-accounts/)을 보세요.

## 상태 점이 안 바뀌어요

세션이 상태를 알리는 방법은 CLI와 버전에 따라 달라요.

| 세션 | 상태를 받는 방법 |
|---|---|
| Claude Code 2.1.295 이상 | Claude가 직접 알리고, Aquila 훅도 함께 써요 |
| 그보다 오래된 Claude Code | Aquila 훅만 (예전 훅 형식을 자동으로 써요) |
| Codex 0.170 이상, 셸에서 직접 알리는 프로그램 | 직접 알려요 |
| 오래된 Codex, 일반 셸 명령 | 출력으로 추측: 3초 넘게 출력하면 작업 중, 3초 조용하면 완료. 점이 흐려요 |
| 원격(SSH) 세션 | 위처럼 출력으로 추측 |

계속 이상하다면:

- **CLI를 업데이트해요.** 최근 Claude Code·Codex는 상태를 정확히 알려요. 오래된 버전은 훅이나 추측으로 돌아가요.
- **세션을 Aquila에서 열어요.** 훅은 Aquila가 띄운 세션에만 붙어요. 셸 탭에서 `claude`를 직접 실행하면 상태를 직접
  알리는 버전에서만 상태가 보여요.
- **흐린 점은 추측이에요.** 출력이 조용해져서 "아마 끝났다"는 뜻이에요.
- **상태 로그를 봐요.** `~/.aquila/status.log`에 상태 보고와 훅 이벤트가 들어올 때마다 남아요. Claude가 일하는 동안
  여기에 아무것도 안 생기면 훅이 Aquila에 닿지 않는 거예요.

**완료**는 그 세션을 보면 조용한 점으로 바뀌고, 알림은 내가 보고 있지 않은 세션에만 와요. **완료 시 알림**은 처음엔
꺼져 있으니 **⚙ 설정**에서 켜요. [상태](/ko/docs/workspace/status/)를 보세요.

<Aside type="tip">
  알림이 아예 안 온다면 macOS **시스템 설정 → 알림**에서 Aquila Agents가 알림을 보낼 수 있는지 확인해요.
</Aside>

## 다시 열었더니 세션이 안 돌아왔어요

앱을 다시 열면 Claude·Codex 대화를 이어서 열어요. 메시지를 한 번도 보내지 않은 Claude 탭은 이어 갈 대화가 아직 없어서
새로 시작해요. 이어서 열지 못하면 탭에 저장된 출력과 함께 **세션을 이어서 열지 못했어요 · 이전 출력 · 읽기 전용**이
뜨고, 같은 폴더의 셸로 떨어져요. CLI를 다시 실행하거나 [세션 기록](/ko/docs/agents/session-history/)(<kbd>⌘Y</kbd>)에서
대화를 찾아요.

## 한글 입력

모든 터미널에서 한글 조합을 처리해요. 조합 중인 글자가 제자리에 보이고, 글자를 조합하는 도중에 누른 Enter·Tab·Esc·
<kbd>⌃C</kbd>는 사라지지 않고 그 글자 다음에 들어가요. 앱 단축키는 키 위치로 알아봐서 한글 입력 상태에서도 돼요. 노트
에디터의 `/` 메뉴는 글자 조합이 끝날 때까지 기다려요.

그래도 글자가 두 번 들어가거나 빠진다면, 누른 키를 그대로 적어서 아래처럼 [알려 주세요](#문제-알리기).

## 설정이 초기화되거나 프로젝트가 사라졌어요

`~/.aquila/config.json`이 올바른 JSON이 아니면 **config.json을 읽지 못했어요: …**가 뜨고 기본값으로 시작해요. 파일은
그대로 남아요. 프로젝트 수정은 파일을 덮어쓰지 않고 실패해요. 앱을 종료하고 JSON을 고친 뒤(오류 메시지에 문제가
적혀 있어요) 다시 열어요. [설정](/ko/docs/reference/config/)을 보세요.

## 노트가 안 열리거나 읽기 전용이에요

- 에디터에서는 켜진 노트 소스 안의 `.md` 파일만 열려요. **⚙ 설정 ▸ 노트 소스…**에서 폴더를 켜요.
- UTF-8이 아닌 파일은 저장하면 바이트가 바뀌니까 읽기 전용으로 열려요.
- 2MB가 넘는 파일은 앞부분만 읽기 전용으로 보여요.

## 로그는 어디 있나요

| 파일 | 내용 |
|---|---|
| `~/.aquila/status.log` | 세션별 상태 보고와 Claude 훅 이벤트. 512KB에서 교체돼요(이전 것은 `status.log.1`) |
| `~/.aquila/config.json` | 프로젝트와 설정 |

## 문제 알리기

[GitHub](https://github.com/kwangyoulsagong/aquila-agents/issues)에 이슈를 열고 다음을 적어 주세요.

- Aquila 버전(**Aquila → Aquila에 관하여**)과 macOS 버전,
- CLI 버전: `claude --version`, `codex --version`,
- 무엇을 했고, 무엇을 기대했고, 실제로 어떻게 됐는지 — 스크린샷이 있으면 좋아요,
- 상태 문제라면 `~/.aquila/status.log`에서 관련된 줄.

<Aside type="caution">
  로그와 스크린샷에는 프로젝트 이름, 경로, 터미널 출력이 들어 있을 수 있어요. 올리기 전에 살펴보고 개인적인 내용은
  지워 주세요.
</Aside>
