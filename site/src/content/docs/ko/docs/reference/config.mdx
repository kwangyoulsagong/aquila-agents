Aquila가 저장하는 건 모두 홈 폴더의 `~/.aquila` 한곳에 있어요. 프로젝트와 설정은 `~/.aquila/config.json`에 있어요.
앱을 다시 설치하거나 업데이트해도 이 폴더는 그대로예요.

## 먼저 앱에서 바꿔요

파일을 직접 열 일은 거의 없어요. 파일에 있는 건 모두 앱에서 바꿀 수 있어요.

| 바꾸고 싶은 것 | 방법 |
|---|---|
| 프로젝트 추가 | 사이드바의 **+ 프로젝트 추가**, 또는 폴더를 사이드바에 끌어다 놓기 |
| 이름 바꾸기, 그룹 옮기기, 빼기 | 프로젝트를 우클릭 |
| 폴더, 기본 에이전트, 브랜치, 셋업 스크립트, 포트, 열 앱, 실행 명령, Figma | 우클릭 → **프로젝트 설정…** |
| 프로젝트별 Claude 계정 | 탭 바의 계정 전환 |
| 그룹 | 그룹 이름을 우클릭, 프로젝트를 끌어서 그룹 사이로 옮기기 |
| 언어, 화면 모드, 완료 시 알림 | 사이드바 왼쪽 아래 **⚙ 설정** |

파일 자체를 보려면 **⚙ 설정 → 설정 파일 열기**를 눌러요. 자세한 흐름은 [프로젝트](/ko/docs/workspace/projects/)를
보세요.

## config.json

파일은 처음 실행할 때 만들어져요. 보통 이렇게 생겼어요.

```json
{
  "language": "ko",
  "accounts": {
    "shared": { "claudeConfigDir": null },
    "personal": { "claudeConfigDir": "~/.claude-personal" }
  },
  "groups": [{ "id": "work" }, { "id": "personal" }, { "id": "remote" }],
  "projects": [
    {
      "id": "web-shop",
      "name": "web-shop",
      "group": "work",
      "account": "shared",
      "path": "~/code/web-shop",
      "portBase": 3000,
      "runCommands": [{ "name": "web", "command": "npm run dev" }]
    }
  ]
}
```

### 맨 위 항목

| 항목 | 형식 | 뜻 |
|---|---|---|
| `language` | `"ko"` \| `"en"` | 화면 언어 |
| `accounts` | 객체 | id별 Claude 계정. `shared`는 그냥 `claude`, `personal`은 따로 된 설정 폴더로 Claude를 실행해요 |
| `groups` | 배열 | 사이드바 그룹 순서: `{ "id": "work" }`. 이름을 바꾸려면 `"label"`을 더해요. `remote`는 SSH 프로젝트용 기본 그룹이에요 |
| `projects` | 배열 | 프로젝트 목록, 사이드바 순서대로 (아래 참고) |
| `notifyDone` | 불리언 | **완료 시 알림**이 켜져 있음. 꺼져 있으면 항목이 없어요 |
| `theme` | `"light"` \| `"dark"` | 고정한 화면 모드. 없으면 macOS를 따라가요 |

### 계정

| 항목 | 뜻 |
|---|---|
| `claudeConfigDir` | 그 계정의 Claude 로그인이 있는 폴더. `shared`의 `null`은 Claude 기본값(`~/.claude`)이에요 |
| `label` | 화면에 보일 이름 (선택) |

<Aside type="caution">
  `shared`는 `null`로 두세요. `"~/.claude"`라고 직접 적으면 Claude가 다른 키체인 항목을 찾아서 원래 로그인이
  사라진 것처럼 보여요.
</Aside>

### 프로젝트 항목

| 항목 | 필수 | 뜻 |
|---|---|---|
| `id` | 예 | 고유 id. 앱에서 추가하면 이름으로 만들어져요 |
| `name` | 예 | 사이드바에 보일 이름 |
| `group` | 예 | 그룹 `id` |
| `account` | 예 | 계정 id(`shared`나 `personal`). **새** Claude 세션부터 적용돼요 |
| `path` | 예 | 프로젝트 폴더. 홈 아래 경로는 `~/…`로 저장해요. 원격 프로젝트면 호스트의 폴더예요 |
| `defaultAgent` | 아니요 | `"claude"`, `"codex"`, `"shell"`: **+**가 먼저 여는 것. 기본은 Claude |
| `defaultBranch` | 아니요 | 새 워크트리 브랜치가 시작할 브랜치. 기본은 지금 체크아웃된 브랜치 |
| `setupScript` | 아니요 | 새 워크트리에서 에이전트보다 먼저 한 번 실행해요 |
| `portBase` | 아니요 | 세션에 `PORT`로 이 숫자를 넘겨요. 워크트리마다 +10. 1024–65000 |
| `openIn` | 아니요 | **열 앱**에 쓸 macOS 앱 이름. 예: `"Visual Studio Code"` |
| `remote` | 아니요 | SSH 프로젝트: `~/.ssh/config`의 `{ "alias": "my-host" }`, 호스트 쪽 `claudeConfigDir`(선택) |
| `figma` | 아니요 | `true`면 그 프로젝트의 Claude·Codex 탭에 Figma MCP가 붙어요. 로컬 프로젝트만 |
| `runCommands` | 아니요 | 실행 슬롯 명령: `[{ "name", "command", "ready"? }]`. 없으면 `package.json`에 dev가 있을 때 `npm run dev` |

## 파일을 직접 고친다면

- Aquila를 먼저 종료하고, 고친 다음 다시 열어요. 그래야 앱에 바뀐 내용이 보여요.
- 올바른 JSON으로 두세요. 파일을 읽지 못하면 **config.json을 읽지 못했어요: …**가 뜨고 기본값으로 시작해요.
- 파일을 읽지 못하는 동안 사이드바에서 하는 프로젝트 수정은 파일을 기본값으로 덮어쓰지 않고 **실패**해요. 다른 걸
  바꾸기 전에 JSON을 고치고 앱을 다시 열어요.

## ~/.aquila에 있는 것

<FileTree>

- ~/.aquila/
  - config.json 프로젝트, 계정, 그룹, 언어, 화면 모드
  - state.json 다시 열 때 쓸 열린 탭과 분할 배치
  - scrollback/ 다시 열 때 쓸 탭별 마지막 출력 (일반 텍스트)
  - claude-hooks.json (와 변형 파일들) Aquila가 띄우는 세션에 넘기는 Claude 설정
  - status.log 세션 상태 이벤트 (512KB에서 교체)
  - context/ Claude 탭별 컨텍스트 사용량
  - first-run.json 시작 점검 상태, 직접 지정한 CLI 경로
  - guide.json 둘러보기를 권했는지
  - release-notes.json 마지막으로 본 릴리스 노트 버전
  - global-shortcut.json 전역 단축키
  - history.json 지난 세션 이름과 즐겨찾기
  - usage-limits.json 계정별로 알게 된 사용 한도
  - news-cache.json AI 트렌드 캐시
  - applies/ 트렌드 적용 결정
  - mcp/ 세션용 Figma MCP 설정
  - graph/ 노트 소스, 노트 색인, 링크 결정
  - vaults/ 내 폴더별 노트 설정
  - notes-seen/ 노트마다 마지막으로 봤을 때의 내용
  - explorer.json 고정·최근 노트, 탐색기 설정
  - runs.json 실행 슬롯 상태
  - extensions/ 내 확장
  - extensions.json 켠 확장 목록
  - extensions-data/ 확장이 저장한 데이터

</FileTree>

이 중 어떤 것도 어딘가로 올리지 않아요. [개인정보](/ko/docs/reference/privacy/)를 보세요.

<Aside type="tip">
  "모두 `~/.aquila`에"의 예외가 하나 있어요. 노트 폴더 설정을 **공유**로 저장하면 팀도 쓸 수 있게 그 폴더 안에
  `.aquila-vault.json`으로 써요.
</Aside>

## Agentrix에서 옮겨 오기

Aquila의 예전 이름은 Agentrix예요. 처음 실행할 때 `~/.aquila/config.json`이 없고 `~/.agentrix`가 있으면 예전 폴더를
복사해 와요. 훅 설정 파일만 빼고요(새로 만들어요). 예전 `~/.agentrix` 폴더는 그대로 두니, 괜찮으면 직접 지워요.
