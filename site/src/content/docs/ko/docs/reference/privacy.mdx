Aquila는 이미 쓰는 CLI를 담는 그릇이에요. CLI를 그대로 실행하고, 자기 데이터는 `~/.aquila`에 두고, CLI 설정에는
손대지 않아요. 이 페이지에 무엇을 건드리는지 정확히 적었어요.

## CLI 설정은 그대로예요

### Claude Code

상태 점을 띄우려면 Claude 훅이 필요해요. Aquila는 **자기가 띄우는 세션에만**, 자기 설정 파일을 넘겨서 훅을 붙여요.

```sh
claude --settings ~/.aquila/claude-hooks….json
```

- 내 `~/.claude/settings.json`, 내 훅, `CLAUDE.md`, MCP 서버, 슬래시 명령은 바뀌지 않고 모두 그대로 적용돼요.
- 훅은 내 Mac 안의 수신기(`127.0.0.1`)로만 알려요.
- 내 Claude 상태 줄(status line)이 있으면 그대로 두고, 그 탭에는 컨텍스트 게이지만 안 보여요. 이걸 알아보려고 설정을
  읽기만 해요.
- 평소 터미널에서 쓰는 `claude`는 영향이 없어요.

### Aquila가 절대 쓰지 않는 파일

- `~/.claude`, `~/.claude-*`와 그 안의 파일
- `~/.codex`
- 셸 rc 파일(`~/.zshrc` 등)

다만 [두 번째 Claude 계정](/ko/docs/agents/claude-accounts/)을 위한 예외가 두 가지 있어요. 둘 다 직접 눌렀을 때만이에요.

1. 로그인 안 된 계정의 **설정**을 누르면 그 계정의 설정 폴더(`~/.claude-personal` 같은 `~/.claude-*` 폴더만)를
   만들고 거기서 Claude 세션을 열어요. 로그인 정보는 늘 그렇듯 Claude가 직접 써요.
2. **터미널에서도 `claude-personal` 쓰기**는 미리보기를 보여 준 뒤 **~/.zshrc에 추가**를 누르면 `~/.zshrc` 끝에 함수
   한 줄을 더해요. 셸에 이미 그 이름이 있으면 건너뛰어요.

<Aside type="note">
  Aquila는 Claude나 Codex 토큰을 저장하지 않아요. 로그인은 CLI 안에서 하고, CLI가 평소처럼 보관해요.
</Aside>

### 읽기만 하는 것

다음은 읽기만 하고 절대 쓰거나 이름을 바꾸거나 지우지 않아요.

- **세션 기록** — 계정별 설정 폴더의 Claude 대화 기록, Codex의 세션 파일과 데이터베이스.
- **사용량 게이지** — 같은 Claude 대화 기록과 Codex 세션 파일로 사용량을 추정해요.
- **계정 상태** — 계정마다 Claude 설정에 로그인이 있는지.

## 프로젝트 파일

| 무엇 | 언제 쓰나요 |
|---|---|
| 레포 | 내가 할 때만: [변경사항 패널](/ko/docs/agents/changes-panel/)에서 스테이지하거나 되돌릴 때(되돌리기는 먼저 백업해요 — 추적 중인 파일은 `git stash` 항목, 추적 안 하는 파일은 휴지통), 또는 내가 만든 워크트리 |
| 노트 그래프 | 쓰지 않아요. 색인을 만들려고 Markdown을 읽기만 해요 |
| 노트 에디터 | 내 수정만, 바이트 그대로 저장. 속성·표 수정은 한 줄만 바꿔요 |
| 노트 링크 | **`[[링크]]` 넣기**, **링크로 바꾸기**, 이름 바꾸기·옮기기 뒤 **고치기**를 누를 때만 |
| 노트 탐색기 | 새로 만들기, 이름 바꾸기, 옮기기, 휴지통 — 모두 내가 할 때. 휴지통은 늘 물어봐요 |
| 이게 뭐야? | **노트로 저장**만 파일을 써요 |
| 공유 폴더 설정 | **공유**를 고를 때만: 그 노트 폴더의 `.aquila-vault.json` |

그 밖에 Aquila가 두는 것(노트 색인, 노트를 마지막으로 봤을 때의 내용, 탭 배치, 다시 열 때 쓸 출력)은 모두
`~/.aquila`에 있어요. 전체 목록은 [설정](/ko/docs/reference/config/)을 보세요.

## 네트워크

Aquila에는 분석이나 원격 측정(telemetry)이 없어요. Aquila가 스스로 인터넷에 접속하는 경우는 이것뿐이에요.

| 무엇 | 언제 | 어디로 |
|---|---|---|
| 업데이트 확인 | 실행할 때와 6시간마다 | 이 프로젝트의 GitHub 릴리스. 내려받지는 않고 새 버전이 나왔다고 알려만 줘요 |
| [AI 트렌드](/ko/docs/agents/ai-trends/) | 패널을 열 때(30분 캐시)나 ↻를 누를 때만 | 공개 피드: GitHub 릴리스, RSS/Atom 블로그, Hacker News, Hugging Face 논문 등 |
| 트렌드 적용 | 누를 때 | 고른 글 |

물론 CLI는 평소처럼 자기 서비스와 통신해요. [원격 호스트](/ko/docs/agents/remote-ssh/) 세션은 내 `~/.ssh/config`로
`ssh`를 쓰고, [미리보기](/ko/docs/agents/preview/)는 내 로컬 dev 서버를 불러와요.

### Aquila가 직접 Claude를 부를 때

몇 가지 기능은 내 Claude 계정으로 숨은 한 턴짜리 `claude -p`를 실행해요. 다른 Claude 요청처럼 요금제 사용량을 써요.

| 기능 | 언제 |
|---|---|
| [이게 뭐야?](/ko/docs/notes/what-is-this/) | **Claude에게 묻기**를 누를 때마다 한 번, 보낼 내용을 그대로 보여 준 뒤 |
| AI 트렌드 요약 | 누를 때만 |
| 폴더 설정 → **Claude로 만들기** | 누를 때만. 폴더 개요(폴더·예시 파일 이름, 개수, frontmatter 키, 자주 쓰는 제목)만 보내고 노트 본문은 보내지 않아요 |
| 트렌드 적용 | 누를 때만 |
| Figma → **연결 확인** | 누를 때만 |
| 링크 제안의 AI 추출 | **기본은 꺼져 있어요.** 노트 소스에서 켜면 바뀐 노트를 뒤에서 처리해요. 노트 본문(노트당 4,000자까지)을 공용 계정으로 보내고, 소스당 하루 40개까지, 배터리 절약 중에는 돌지 않아요 |

이 실행에는 도구가 없어서 레포를 읽거나 바꿀 수 없어요. 예외 두 가지는 필요한 것만 받아요: Figma 확인은 Figma의
`whoami`를 부를 수 있고, 트렌드 적용은 적용할 프로젝트를 읽을 수 있어요(고치지는 못해요). 이게 뭐야?는 빈 임시
폴더에서 실행돼요.

<Aside type="note">
  사용량 게이지도 몇 분마다 로그인된 계정마다 `claude -p /usage`를 실행해요. 한도를 읽는 로컬 CLI 명령이라 모델을
  부르지 않고 사용량도 쓰지 않아요.
</Aside>

## 내 Mac에 저장하는 것

Aquila가 저장하는 건 모두 내 Mac의 `~/.aquila`에 있어요. 알아 둘 두 가지:

- **다시 열 때 쓸 출력:** 열린 탭마다 마지막 출력(최대 2,000줄, 일반 텍스트)을 `~/.aquila/scrollback/`에 저장해서
  다시 실행해도 돌아오게 해요. 탭을 닫으면 그 파일도 지워요.
- **상태 로그:** `~/.aquila/status.log`에 문제 해결용으로 상태 이벤트와 훅 이벤트 이름을 남겨요(512KB에서 교체).

Aquila가 저장한 걸 모두 지우려면 앱을 종료하고 `~/.aquila`를 지우면 돼요.
