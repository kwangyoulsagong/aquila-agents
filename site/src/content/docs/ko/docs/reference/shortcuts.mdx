앱 단축키는 앱 안의 가이드(<kbd>⌘/</kbd> → **모든 단축키**)와 macOS 메뉴 막대에도 다 있어요. 앱 안에서 언제든
찾아볼 수 있어요.

<Aside type="tip">
  단축키는 글자가 아니라 키 위치로 알아봐요. 그래서 한글 입력 상태에서도 그대로 돼요. 그 키가 `ㅅ`을 입력할 때도
  <kbd>⌘T</kbd>는 동작해요.
</Aside>

## 기본

| 키 | 동작 |
|---|---|
| <kbd>⌘K</kbd> | 명령 팔레트: 프로젝트나 세션으로 가거나 아무 명령이나 실행 |
| <kbd>⌘/</kbd> | 가이드 · 단축키 |
| <kbd>⌘J</kbd> | 다음 대기 세션으로 (입력 필요 → 오류 → 완료 순, 오래 기다린 것부터) |
| <kbd>⌘Y</kbd> | 세션 기록 |
| <kbd>⌘,</kbd> | 설정 (⚙ 메뉴) |

## 세션 · 프로젝트

| 키 | 동작 |
|---|---|
| <kbd>⌘T</kbd> | 지금 프로젝트에서 Claude 열기 |
| <kbd>⇧⌘T</kbd> | Codex 열기 |
| <kbd>⌥⌘T</kbd> | 셸 열기 |
| <kbd>⌘W</kbd> | 세션 닫기 (빈 분할에서는 분할 닫기) |
| <kbd>⌘1</kbd> – <kbd>⌘9</kbd> | 사이드바의 1–9번째 프로젝트로 |

탭 바의 **+**를 우클릭하면 새 Claude·Codex·셸이나 워크트리 세션을 열 수 있어요.
[세션](/ko/docs/workspace/sessions/)과 [워크트리](/ko/docs/agents/worktrees/)를 보세요.

## 터미널

| 키 | 동작 |
|---|---|
| <kbd>⇧⌘C</kbd> | 마지막 응답 복사 |
| <kbd>⇧⌘E</kbd> | URL·경로 고르기: 화면의 URL·경로·커밋을 라벨 키로 골라 복사 |
| <kbd>⌘F</kbd> | 터미널에서 찾기 |
| <kbd>⌘V</kbd> | 붙여 넣기. 이미지나 복사한 파일은 경로로 들어가요 |

[터미널 도우미](/ko/docs/agents/terminal-helpers/)를 보세요.

## 화면 분할

| 키 | 동작 |
|---|---|
| <kbd>⌘D</kbd> | 오른쪽으로 분할 (최대 4개) |
| <kbd>⇧⌘D</kbd> | 아래로 분할 |
| <kbd>⌥⌘←</kbd> <kbd>⌥⌘→</kbd> <kbd>⌥⌘↑</kbd> <kbd>⌥⌘↓</kbd> | 옆 분할로 이동 |
| <kbd>⇧⌘↩</kbd> | 분할 확대 / 되돌리기 (분할 머리를 더블클릭해도 돼요) |
| <kbd>⇧⌘F</kbd> | 전체 창 / 되돌리기: 사이드바와 탭을 숨기고 지금 분할만 보여줘요 |
| <kbd>⌥⇧⌘←</kbd> <kbd>⌥⇧⌘→</kbd> <kbd>⌥⇧⌘↑</kbd> <kbd>⌥⇧⌘↓</kbd> | 분할 크기 조절 |

경계선을 끌어도 크기가 바뀌고, 더블클릭하면 반반이 돼요. <kbd>Esc</kbd>는 CLI 몫이라 확대나 전체 창에서 나가지
않아요. [화면 분할](/ko/docs/workspace/split-panes/)을 보세요.

## 패널

| 키 | 동작 |
|---|---|
| <kbd>⇧⌘G</kbd> | 변경사항 보기 |
| <kbd>⇧⌘P</kbd> | 미리보기 보기 |
| <kbd>⇧⌘R</kbd> | 실행 패널 보기 |
| <kbd>⇧⌘N</kbd> | 그래프 보기 |
| <kbd>⌘O</kbd> | 노트 빠르게 열기 |
| <kbd>⇧⌘O</kbd> | 노트 탐색기 |

## 노트 편집기

노트 안에 커서가 있을 때 동작해요.

| 키 | 동작 |
|---|---|
| <kbd>⌥⇧↑</kbd> / <kbd>⌥⇧↓</kbd> | 블록 위·아래로 옮기기 |
| <kbd>/</kbd> | 블록 메뉴 (빈 줄에서) |
| <kbd>⌘E</kbd> | 읽기 모드 켜기·끄기 |
| <kbd>⌘S</kbd> | 바로 저장 (노트는 알아서도 저장돼요) |
| <kbd>⌘F</kbd> | 노트에서 찾기 |
| <kbd>⌘D</kbd> | 다음 일치 항목 선택 |
| <kbd>⌘Z</kbd> / <kbd>⇧⌘Z</kbd> | 되돌리기 / 다시 하기 |
| <kbd>Tab</kbd> / <kbd>⇧Tab</kbd> | 표 안에서: 다음 / 이전 칸 |
| <kbd>↩</kbd> | 표 안에서: 줄 추가 |
| `[[` | 링크할 노트 이름 제안 |

<Aside type="note">
  노트 편집기와 입력칸에서는 <kbd>⌘W</kbd>가 세션을 닫지 않아요. 노트 편집기에서 <kbd>⌘F</kbd>·<kbd>⌘D</kbd>는
  편집기 몫이라 터미널을 찾거나 화면을 나누지 않아요.
</Aside>

## 노트 탐색기

파일 목록 트리에 포커스가 있을 때 동작해요.

| 키 | 동작 |
|---|---|
| <kbd>↑</kbd> <kbd>↓</kbd> | 트리에서 이동 |
| <kbd>←</kbd> <kbd>→</kbd> | 폴더 접기 / 펼치기 |
| <kbd>↩</kbd> | 노트 열기 |
| <kbd>⌘N</kbd> | 새 노트 |
| <kbd>F2</kbd> | 이름 바꾸기 |
| <kbd>⌘⌫</kbd> | 휴지통으로 (먼저 물어봐요) |
| <kbd>⌘Z</kbd> | 마지막 옮기기·이름 바꾸기·새 폴더·새 노트 되돌리기 |

## 그래프 (주변 보기)

| 키 | 동작 |
|---|---|
| 화살표 키 | 항목 사이 이동 |
| <kbd>↩</kbd> | 고른 항목을 가운데로 |
| <kbd>⌘↩</kbd> | 고른 항목 열기 |
| <kbd>⌫</kbd> | 뒤로 |
| <kbd>⌘</kbd>클릭 | 열기 (주변) · 원 여러 개 고르기 (전체 지도) |

## 전역 단축키

어느 앱에서든 누르면 Aquila가 앞으로 오고 가장 오래 기다린 세션이 열리는 키를 하나 정할 수 있어요. **⚙ 설정 →
전역 단축키…**에서 키를 녹음하기 전까지는 꺼져 있어요. 키에는 <kbd>⌘</kbd>·<kbd>⌃</kbd>·<kbd>⌥</kbd> 중 하나가
있어야 하고, 위 단축키와 겹치면 안 돼요.
