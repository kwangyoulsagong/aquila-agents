Aquila Agents를 처음 열면 **시작하기 전에**라는 짧은 점검 화면이 떠요. 이 Mac에 필요한 게 있는지 확인하고, 첫
프로젝트 폴더 추가를 도와줘요. 1분이면 끝나요.

<Shot id="firstRun" caption="시작 점검: 셸 PATH, CLI, git, 프로젝트 폴더." />

## 무엇을 확인하나요

| 항목 | 뜻 | 없으면 |
|---|---|---|
| **셸 PATH 불러옴** | 로그인 셸의 `PATH`를 읽었다는 뜻이에요. Homebrew, fnm, nvm 등으로 설치한 도구도 찾아요. | **셸 PATH를 못 읽었어요**가 떠요. 시스템 PATH로 찾고, 못 찾은 CLI는 경로를 직접 지정해요(아래 참고). |
| **Claude Code** | `claude` 명령과 버전, 경로. | 보이는 설치 명령을 복사해 터미널에서 실행하고 돌아와요. |
| **Codex** | `codex` 명령. **선택** 항목이에요. | 위와 같아요. Claude만 쓴다면 그냥 둬도 돼요. |
| **git** | 변경 패널과 워크트리에 필요해요. | `xcode-select --install`을 복사해 실행해요. |
| **프로젝트 폴더** | 사이드바에 있는 프로젝트 수. | 하나 추가해요(아래 참고). |
| **로그인은 CLI 안에서** | 확인 항목이 아니라 안내예요. | Claude는 처음 열 때 `/login`, Codex는 로그인을 안내해요. |

창으로 돌아오면 저절로 다시 확인해요. 터미널에서 CLI를 설치하고 돌아오기만 하면 돼요. **다시 확인**을 누르면
바로 확인하고, 그 전에 셸 PATH도 다시 읽어요.

<Aside type="note">
  Aquila는 토큰을 저장하지 않아요. 에이전트는 늘 하던 대로 CLI 안에서 로그인하고, 그 CLI에 로그인된 계정과
  요금제를 그대로 써요.
</Aside>

## CLI를 못 찾을 때

Aquila는 PATH에서 각 도구를 찾아요. 셸 **alias**나 함수는 안 되고 실제 파일이 있어야 해요.

설치했는데 **찾을 수 없어요**나 **실행되지 않아요**가 뜨면:

<Steps>

1. 옆의 **경로 지정…**을 눌러요.

2. 실행 파일을 골라요(예: `~/.local/bin/claude`).

3. Aquila가 `--version`으로 실행해 봐요. 실행되면 **직접 지정**으로 표시되고, 새 세션은 그 파일을 그대로 써요.
   실행되지 않으면 **이 파일은 실행되지 않아요**가 뜨고 저장되지 않아요.

</Steps>

**PATH 사용**을 누르면 다시 이름으로 찾아요.

## 첫 프로젝트 추가하기

프로젝트는 Mac에 있는 폴더예요. 보통 git 저장소고, 세션은 그 폴더에서 열려요.

**프로젝트 폴더** 항목에서 둘 중 하나를 해요.

- Finder에서 폴더를 하나 이상 끌어다 놓기
- **폴더 추가…**를 눌러 폴더 고르기

폴더는 사이드바 첫 번째 그룹에 공용 Claude 계정으로 들어가요. 이름, 위치, 설정은 나중에 바꿀 수 있어요.
[프로젝트](/ko/docs/workspace/projects/)를 참고하세요.

## 마치기

**시작하기**를 눌러요. **나중에 하기**나 <kbd>Esc</kbd>로 닫아도 되고, 어떻게 닫든 다시 저절로 뜨지 않아요.
설정하지 않은 선택 항목은 꺼진 채로 남아요.

다시 열려면 <kbd>⌘K</kbd>를 누르고 **시작 점검**을 실행해요. 모든 항목을 다시 확인해요.

점검 화면을 닫으면 앱 안 가이드를 둘러볼지 한 번 물어봐요(**둘러보기** / **건너뛰기**). 가이드는 사이드바 아래의
**?**나 <kbd>⌘/</kbd>로 언제든 열 수 있어요.

## 설정은 어디에 있나요

Aquila가 저장하는 건 모두 홈 폴더의 `~/.aquila`에 있어요. 알아 두면 좋은 파일은 이거예요.

| 파일 | 내용 |
|---|---|
| `~/.aquila/config.json` | 프로젝트, 그룹, 계정, 언어 등 설정 |
| `~/.aquila/state.json` | 열린 탭과 분할 배치([다시 열면 그대로](/ko/docs/workspace/restore-and-power/)에 써요) |
| `~/.aquila/first-run.json` | 시작 점검을 마쳤는지, 직접 지정한 CLI 경로 |

`config.json`을 열려면 사이드바 왼쪽 아래 **⚙ 설정**에서 **설정 파일 열기**를 골라요. 대부분은 앱에서 바꿀 수
있어서 직접 열 일은 드물어요. 전체 형식은 [설정 파일](/ko/docs/reference/config/)을 보세요.

<Aside type="caution">
  Aquila는 CLI 설정을 건드리지 않아요. `~/.claude`, `~/.codex`, 셸 rc 파일에 마음대로 쓰지 않아요. 예외는 하나,
  [두 번째 Claude 계정](/ko/docs/agents/claude-accounts/)을 설정할 때 직접 눌러 확인한 경우에만 `~/.zshrc`에
  `claude-personal` 함수를 추가하는 거예요.
</Aside>
