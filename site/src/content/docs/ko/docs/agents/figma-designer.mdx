Figma를 연결하면 에이전트가 Figma 공식 MCP 서버로 디자인을 읽을 수 있어요. Aquila는 여기에 두 가지를 더해요.
Figma 링크를 붙여 넣으면 뜨는 **프롬프트 칩**, 그리고 실행 중인 앱과 Figma 프레임을 함께 보여 줘서 다른 곳을 찾게
해 주는 **디자이너**예요.

## Figma 연결하기

Figma는 **프로젝트마다** 켜요.

<Steps>

1. <kbd>⌘K</kbd> → **Figma 연결…**을 실행해요(**도움말** 메뉴에도 있어요). 프로젝트 설정의 **Figma MCP** 칸이 열려요.

2. **켜기**로 바꿔요.

3. **Claude에서 로그인**(또는 **저장하고 로그인**)을 눌러요. 새 Claude 탭이 열리고 `/mcp`가 입력돼요. <kbd>Enter</kbd>를
   누르고 **figma** → **Authenticate**를 고른 뒤 브라우저에서 로그인을 마쳐요.

4. 선택: **연결 확인**을 누르면 Figma 계정과 플랜을 보여 줘요.

</Steps>

Codex는 터미널에서 한 번 로그인해요.

```sh
codex mcp login figma
```

<Shot id="figma" caption="프로젝트 설정의 Figma MCP와, 링크를 붙여 넣으면 뜨는 칩." />

### 무엇이 바뀌나요

- 그 프로젝트의 새 Claude·Codex 탭이 Figma MCP 서버를 써요. 직접 등록한 MCP 서버는 그대로 두고, 레포나 `~/.codex`에는
  아무것도 쓰지 않아요.
- 이미 열린 탭은 시작할 때 설정 그대로예요. 설정 창에서 **저장하고 다시 열기**를 누르면 다시 열리고, 대화는 이어져요.
- 로그인 정보는 Aquila가 아니라 CLI에(Claude 계정마다) 저장돼요.

<Aside type="note" title="Figma 플랜">
  어떤 Figma 기능은 시트와 플랜에 따라 달라요. **디자인 → 코드**는 Dev 또는 Full 시트가 필요하고, **Code Connect**는
  Organization 플랜이 필요할 수 있어요. Aquila는 플랜 옆에 힌트로만 보여 주고 막지는 않아요. 플랜을 모르면
  **Figma 문서**를 확인하세요.
</Aside>

## Figma 링크를 프롬프트로 바꾸기

Claude나 Codex 탭에 Figma 링크를 붙여 넣거나, 입력하거나, 끌어다 놓으면 터미널 위에 칩이 떠요.

| 묶음 | 칩 | 에이전트에게 부탁하는 것 |
|---|---|---|
| **디자인** | **앱과 비교** | 프레임을 실행 중인 앱과 비교해 간격·색·글꼴·크기 차이를 고치기 |
| **디자인** | **코멘트 → TODO** | 파일의 코멘트를 TODO 목록으로 만들고 백엔드 작업 표시하기 |
| **구현** | **컴포넌트·토큰으로 구현** | 우리 디자인 시스템의 컴포넌트와 토큰으로 프레임 구현하기 |
| **구현** | **에셋 받기** | 프레임의 에셋 내려받기 |

FigJam 보드에서는 **흐름 → 화면**(화면·상태 목록과 백엔드 TODO)과 **코멘트 → TODO**가 떠요.

칩을 누르면 입력창의 링크 뒤에 프롬프트가 붙어요. Enter는 누르지 않아요. <kbd>Enter</kbd>로 보내거나 **×**로 칩을
닫아요.

<Aside type="tip">
  Claude 탭에서 **앱과 비교**와 **컴포넌트·토큰으로 구현**은 Claude in Chrome으로 결과를 확인하는 단계도 부탁해요.
  Figma 프레임과 실행 중인 앱을 열어 레이어별로 대조하고, MCP 데이터가 놓친 부분을 고쳐요. Codex에는 MCP만 쓰는
  프롬프트가 들어가요.
</Aside>

## 앱과 디자인 비교하기 (디자이너)

디자이너는 Figma를 켠 프로젝트의 [미리보기](/ko/docs/agents/preview/)에 있어요.

<Steps>

1. 미리보기를 열고(<kbd>⇧⌘P</kbd>) **디자이너**를 눌러요.

2. **Figma 링크** 칸에 Figma 프레임 링크를 붙여 넣어요. 처음 한 번은 그 화면 안에서 Figma에 로그인해요. 로그인은
   유지돼요.

3. **배치**를 골라요: **위아래**, **좌우**, **겹쳐 보기**.

</Steps>

<Shot id="designer" caption="겹쳐 보기 + 차이: 다른 픽셀만 밝게 남아요." />

**겹쳐 보기**는 두 화면을 캡처해 Figma 프레임을 앱 위에 겹쳐요.

- **Figma 투명도**를 움직여 둘 사이를 오가요.
- **차이**를 켜면 같은 픽셀은 검게, 다른 곳만 밝게 보여요.
- 앱이 바뀐 뒤에는 ↻(**다시 캡처**)를 눌러요.

**에이전트에 보내기**는 두 스크린샷과 차이를 고쳐 달라는 요청을 포커스된 Claude·Codex 탭에 붙여 넣어요. 이번에도
Enter는 직접 눌러요.

<Aside type="tip">
  Figma **프로토타입** 링크를 쓰세요. Figma 화면 없이 프레임만 보여서 앱과 가장 잘 맞아요.
</Aside>

디자이너에 Figma 링크가 열려 있으면 [요소 선택](/ko/docs/agents/preview/#요소를-골라-에이전트에-알려-주기)에도
프레임 링크가 붙고, 고른 요소를 디자인과 비교해 달라는 요청이 들어가요.

Figma는 로컬 프로젝트에서만 돼요.
