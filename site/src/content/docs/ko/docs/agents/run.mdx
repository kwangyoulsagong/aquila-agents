Run 슬롯은 프로젝트에 필요한 오래 도는 명령(dev 서버, 테스트 워처, 타입 체커)을 에이전트 탭과 따로 돌려요. 각각이
떠 있는지 한눈에 보고, 로그를 읽고, 주소를 [미리보기](/ko/docs/agents/preview/)에서 열 수 있어요.

<Shot id="run" caption="명령마다 한 줄, 아래에 로그, 주소는 프리뷰에서 바로 열어요." />

## Run 패널 열기

<kbd>⇧⌘R</kbd>를 누르거나, 탭 바의 **▶ 실행**을 누르거나, <kbd>⌘K</kbd> → **실행 패널 보기**를 실행해요.

명령마다 상태 점이 붙은 줄이 있어요. 줄을 고르면 아래에 로그가 나와요. **실행**으로 고른 명령을 시작하고, 떠 있는
동안에는 그 자리에 **다시 실행**과 **중지**가 나와요.

## 점의 의미

| 점 | 상태 | 뜻 |
|---|---|---|
| 초록 원 | **실행 중** | 명령이 떠 있어요. |
| 고리 | **종료됨** | 정상 종료(exit 0)했거나 직접 멈췄어요. |
| `!` 네모 | **오류** | 0이 아닌 코드로 끝났거나 오류 줄을 출력했어요. 그 줄을 보여 줘요. |

오류 줄은 `Error`, `EADDRINUSE`, `OOM`, `out of memory`, `NaN`이 들어간 줄이에요. 아직 떠 있는 워처가
`compiled successfully`, `Found 0 errors`, `ready in …`, `hmr update` 같은 "다시 정상" 줄을 출력하면 **실행 중**으로
돌아와요.

## 실행할 명령 정하기

따로 정하지 않으면 `package.json`의 `dev` 스크립트를 프로젝트가 쓰는 패키지 매니저로 실행해요(`pnpm dev`,
`yarn dev`, `bun run dev`, 아니면 `npm run dev`).

직접 정하려면:

<Steps>

1. 프로젝트를 우클릭 → **프로젝트 설정…**.

2. **실행 명령**에 한 줄에 하나씩 `이름: 명령` 형식으로 적어요.

   ```text
   web: npm run dev
   api: go run ./cmd/api  # ready: Listening on
   types: npx tsc --noEmit --watch
   ```

3. 저장해요. 줄마다 Run 패널에 한 줄씩 생겨요.

</Steps>

### "정상" 줄 직접 정하기

도구가 회복될 때 출력하는 문구가 따로 있으면 줄 끝에 `# ready: <문구>`를 붙여요. 오류가 난 뒤 그 문구가 든 줄이
나오면(대소문자 무관) **실행 중**으로 돌아와요. 셸 주석이라 명령 자체는 바뀌지 않아요.

## 프리뷰에서 앱 열기

실행 중인 명령이 로컬 주소(`http://localhost:5173`, `http://0.0.0.0:3000` 등)를 출력하면 그 주소가 기억되고,
**프리뷰에서 열기**로 미리보기 패널에서 바로 열 수 있어요. 이 주소는 미리보기의 개발 서버 목록에도 들어가요.

## 워크트리마다, 다시 열어도 그대로

- 패널은 **포커스된 탭**을 따라가요. [워크트리](/ko/docs/agents/worktrees/)마다 실행과 로그가 따로라서 두 브랜치가
  각자 dev 서버를 띄울 수 있어요.
- 프로젝트에 **포트 시작 번호**가 있으면 실행에 `PORT` 변수가 넘어가요(워크트리마다 +10). 패널 머리에 표시돼요.
- 앱을 끌 때 떠 있던 실행은 다음에 앱을 열면 다시 시작돼요. 프로젝트, 명령, 폴더가 그대로 있을 때만요.

<Aside type="note">
  중지하면 프로세스 그룹 전체를 멈춰서, `npm run dev`가 띄운 서버 같은 자식 프로세스가 남지 않아요. 앱을 끄면 모든
  실행이 멈춰요. Run 슬롯은 로컬 프로젝트에서만 돼요.
</Aside>
