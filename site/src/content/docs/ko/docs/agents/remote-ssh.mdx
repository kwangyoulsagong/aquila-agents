프로젝트를 SSH로 접속하는 다른 컴퓨터(개발 서버, 클라우드 VM)에 둘 수 있어요. 세션은 그 호스트의 tmux 안에서 돌아서,
와이파이가 끊기거나 노트북을 덮어도 에이전트는 계속 일하고, 연결이 돌아오면 Aquila가 다시 붙어요.

<Shot id="remote" caption="원격 프로젝트 추가: 추가하기 전에 호스트를 확인해요." />

## 시작하기 전에

- 호스트가 `~/.ssh/config`에 있고 키로 로그인할 수 있어야 해요(ssh-agent를 그대로 써요). Aquila는 비밀번호나 키를
  저장하지 않아요.
- 호스트에 `tmux`가 있어야 해요. `claude`나 `codex`도 호스트에 설치하고 호스트에서 로그인해 두세요.

<Aside type="tip">
  ssh가 비밀번호나 새 호스트 키 확인을 물어보면, 먼저 터미널에서 `ssh <호스트>`를 한 번 실행하세요. 그다음부터는
  호스트 확인이 통과해요.
</Aside>

## 원격 프로젝트 추가하기

<Steps>

1. <kbd>⌘K</kbd> → **원격 서버 추가…**를 실행하거나, 사이드바의 **+ 프로젝트 추가** → **원격 서버(SSH)…**를 눌러요.

2. **SSH 호스트**: `~/.ssh/config`의 Host 이름을 적어요(그 파일에서 추천해 줘요).

3. **호스트 확인**을 눌러 호스트 상태를 봐요(아래 참고). 건너뛰어도 추가할 때 같은 확인을 해요.

4. **호스트의 폴더**: 경로를 적거나(`~/…`는 원격 홈) **찾아보기…**로 골라요. git 저장소인 폴더에는 **git**이 붙어요.

5. 선택: **이름**, 그리고 호스트의 Claude가 기본값이 아닌 `CLAUDE_CONFIG_DIR`을 쓰면 **호스트의 Claude 설정 폴더**(비우면
   `~/.claude`).

6. **추가**를 눌러요. 사이드바의 원격 그룹에 들어가요.

</Steps>

호스트에 연결할 수 없거나, tmux가 없거나, 폴더가 없으면 안내와 함께 추가가 멈춰요.

### 호스트 확인에서 보이는 것

| 줄 | 뜻 |
|---|---|
| **시스템** | 호스트의 OS와 아키텍처. |
| **claude / codex / tmux / git 있음** 또는 **없음** | 도구마다 버전. 없는 도구는 복사할 설치 명령이 함께 나와요(보여 주기만 하고 실행하지 않아요). |
| **Claude 로그인됨** / **Claude 로그인 필요** | 호스트의 Claude 로그인 여부. 안 돼 있으면 세션을 열어 거기서 로그인하세요. |
| `KillUserProcesses=yes` 경고 | 일부 Linux 호스트는 마지막 ssh 연결이 끊기면 tmux 세션도 끝나요. 호스트에서 `loginctl enable-linger`를 실행하면 막을 수 있어요. |

## 원격 세션 쓰기

원격 프로젝트에서도 평소처럼 Claude, Codex, 셸을 열어요. 탭마다 호스트에 tmux 세션이 하나씩 생겨요.

- **탭**과 패널 머리에 연결 점이 붙은 호스트 배지가 보여요: **연결 중**, **연결됨**, **다시 연결 중**, **연결 끊김**.
- **연결이 끊기면** 알아서 다시 시도해요(3초, 6초, 12초 뒤, 그다음엔 1분마다). 끊긴 동안 터미널 위 배너에 다음
  시도까지 남은 시간과 **지금 다시 연결**이 떠요. 그동안에도 에이전트는 호스트의 tmux에서 계속 돌아요.
- **탭을 닫으면** 호스트의 tmux 세션도 끝나요. **앱을 끄는 것**은 아니에요. 다음에 열면 돌고 있던 에이전트에 다시
  붙어요.
- 원격 탭의 **상태 점**은 터미널 출력으로 추정해서 추정 표시(<span class="sdot" data-s="estimated"></span>)로 보여요.
  호스트에서는 Claude 훅이 이 Mac에 닿지 않기 때문이에요.

<Aside type="note" title="호스트의 tmux">
  Aquila는 자기 tmux 서버(`tmux -L aquila`)를 따로 띄우고, 설정은 호스트의 `~/.aquila/tmux.conf`에 둬요. 호스트에
  쓰는 파일은 이것 하나예요. 원래 쓰던 tmux 세션과 설정은 건드리지 않아요.
</Aside>

## 원격에서 되는 것

SSH로도 되는 것:

- [변경사항 패널](/ko/docs/agents/changes-panel/) (스테이지·되돌리기 포함)
- 호스트의 Claude·Codex 세션 [세션 기록](/ko/docs/agents/session-history/)과 이어 하기

로컬 프로젝트에서만 되는 것: [워크트리](/ko/docs/agents/worktrees/), [미리보기](/ko/docs/agents/preview/),
[Run 슬롯](/ko/docs/agents/run/), [Figma](/ko/docs/agents/figma-designer/), **다른 앱에서 열기**, 마지막 응답 복사, 포트
시작 번호와 셋업 스크립트, [계정 스위치](/ko/docs/agents/claude-accounts/)(대신 Claude 설정 폴더를 써요).

나중에 호스트, 폴더, Claude 설정 폴더를 바꾸려면 프로젝트를 우클릭 → **프로젝트 설정…**.
