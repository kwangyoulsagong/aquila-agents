변경사항 패널은 에이전트가 프로젝트의 git 작업 트리에서 바꾼 것을 세션 바로 옆에 보여 줘요. 파일이 저장될 때마다
갱신돼서, 창을 벗어나지 않고 따라가며 피드백을 보낼 수 있어요.

<Shot id="changes" caption="실시간 diff. 확인할 파일이 위에 오고, 줄 코멘트를 붙여 넣을 준비가 돼 있어요." />

## 패널 열기

<kbd>⇧⌘G</kbd>를 누르거나 탭 바의 **± 변경**을 눌러요. 한 번 더 누르면 닫혀요.

패널은 **포커스된 탭**을 따라가요. [워크트리](/ko/docs/agents/worktrees/)에서 도는 탭이면 그 워크트리의 변경을
보여 줘요. 아래쪽 줄에 무엇을 보고 있는지와 마지막 갱신 시각이 나와요(예: "git 작업 트리 · 5초 전 업데이트").

## diff 읽기

- 위쪽에 브랜치, ahead/behind 수, 바뀐 파일 목록이 있어요. 파일을 누르면 그 파일로 가고, <kbd>j</kbd> / <kbd>k</kbd>로
  파일 사이를 오가요.
- **보기**: **한 줄** 또는 **나란히**.
- **비교 기준**:
  - **작업 트리** — `HEAD` 대비 커밋하지 않은 변경(추적되지 않는 새 파일 포함).
  - **세션 시작부터** — 세션이 시작된 커밋 이후 전부. 에이전트가 이미 커밋한 작업도 보여요.

패널이 열려 있는 동안 알아서 갱신돼요. **새로고침**으로 바로 갱신할 수도 있어요.

### 한 번 더 볼 파일

어떤 파일은 배지가 붙고 목록 맨 위로 올라가요. 머리에는 **확인할 것 n**이 표시돼요.

| 배지 | 파일 |
|---|---|
| **마이그레이션** | `migrations/` 폴더 안의 파일, `*.sql`, `schema.prisma` |
| **락파일** | `package-lock.json`, `pnpm-lock.yaml`, `yarn.lock`, `Cargo.lock`, `go.sum` 등 |
| **env** | `.env`, `.env.*` |
| **프롬프트** | `CLAUDE.md`, `AGENTS.md`, `*.prompt.*`, `prompts/`, `.claude`의 `agents`·`commands`·`skills` |
| **CI** | `.github/workflows/`, `.gitlab-ci.yml`, `.circleci/` |

## 줄 코멘트를 에이전트에 보내기

<Steps>

1. diff에서 줄을 눌러요. 그 아래에 코멘트 칸이 열려요.

2. 바꿀 내용을 적고 <kbd>⌘Enter</kbd>로 추가해요. 원하는 만큼 여러 줄에 달 수 있어요.

3. **코멘트 붙여넣기 (n)**을 눌러요. 코멘트마다 `파일:줄`과 해당 코드를 붙여 프롬프트 하나로 만들고, 포커스된 세션의
   입력창에 붙여 넣어요.

4. 내용을 확인하고 터미널에서 직접 <kbd>Enter</kbd>를 눌러요.

</Steps>

<Aside type="tip">
  이 패널은 절대 대신 보내지 않아요. 붙여 넣은 뒤에는 항상 Enter를 기다려요. **커밋 메시지**와 **PR 설명**도 같아요.
  에이전트에게 작성을 부탁하는 프롬프트를 붙여 넣어요.
</Aside>

## 스테이지하거나 되돌리기

파일마다, 부분(hunk)마다 버튼이 있어요.

- 파일 전체를 **스테이지** / **언스테이지**.
- 파일 전체를 **되돌리기**.
- 부분 하나만 **스테이지**하거나 **되돌리기**.

되돌리기는 항상 먼저 물어보고, 건드리기 전에 백업해요.

- 추적되는 파일의 변경은 먼저 `git stash`에 저장해요. 그다음 패널에 **git stash에 백업했어요 (…)**가 떠요. 나중에
  `git stash list`로 찾을 수 있어요.
- 추적되지 않는 파일은 지우지 않고 macOS **휴지통**으로 옮겨요.

<Aside type="caution">
  부분 스테이지·되돌리기는 아직 아무것도 스테이지하지 않은 평범한 수정 파일에서만 나와요. 새 파일, 이름이 바뀐 파일,
  일부만 스테이지한 파일은 파일 단위 버튼을 쓰세요.
</Aside>

## 요약을 Markdown으로 복사하기

**Markdown 복사**는 변경 요약을 복사해요. 바뀐 파일과 상태·줄 수, 먼저 볼 파일, 아직 남아 있는 리뷰 코멘트가
들어가요. PR 본문이나 채팅에 붙여 넣으면 돼요.

## SSH 호스트의 프로젝트

[원격 프로젝트](/ko/docs/agents/remote-ssh/)에서도 패널이 돼요. 10초마다(그리고 창으로 돌아올 때나 **새로고침**을
누를 때) 갱신하고, 아래쪽 줄에 호스트와 왕복 시간을 보여 줘요. 되돌린 추적되지 않는 파일은 호스트의
`~/.aquila/trash`로 옮겨요.
