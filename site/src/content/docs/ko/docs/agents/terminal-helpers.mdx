세션은 모두 진짜 터미널이에요. Aquila는 에이전트와 일할 때 자주 하는 일을 돕는 기능을 몇 가지 더해요. 따로 적지
않은 건 Claude, Codex, 셸 탭에서 모두 똑같이 돼요.

<Shot id="terminal" caption="화면의 URL과 경로마다 라벨이 붙어요. 라벨을 치면 복사돼요." />

| 키 | 도우미 |
|---|---|
| <kbd>⌘V</kbd> | 글 붙여넣기, 이미지·복사한 파일은 경로로 |
| <kbd>⇧⌘C</kbd> | 마지막 응답 복사 |
| <kbd>⇧⌘E</kbd> | URL·경로·커밋을 라벨로 고르기 |
| <kbd>⌘F</kbd> | 터미널에서 찾기 |

## 이미지나 파일 붙여 넣기

에이전트에게 스크린샷을 보여 주려면 복사한 뒤 탭에서 <kbd>⌘V</kbd>를 눌러요. Aquila가 이미지를 임시 파일로 저장하고
그 경로를 입력해요. Claude와 Codex는 이렇게 이미지를 첨부해요. 임시 이미지는 하루 뒤 정리돼요.

Finder에서 복사한 파일도 같은 방식으로 경로가 붙어요. Finder에서 터미널로 **파일을 끌어다 놓아도** 돼요("놓으면
경로를 입력해요"). 경로는 셸에 맞게 이스케이프돼서 공백이 있어도 괜찮아요. 일반 글은 평소처럼 붙여 넣어져요.

## 위로 스크롤해도 자리 지키기

위로 스크롤하면 자동 스크롤이 멈춰서, 새 출력이 나와도 아래로 끌려 내려가지 않아요. **맨 아래로** 버튼이 뜨고,
새 출력이 오면 **새 출력**으로 바뀌어요. 누르면 맨 아래로 가요.

## 마지막 응답 복사하기

Claude나 Codex 탭에서 <kbd>⇧⌘C</kbd>(또는 우클릭 → **마지막 응답 복사**)를 누르면 에이전트의 마지막 답을 복사해요.
화면이 아니라 세션 기록에서 읽어서, 답 전체를 도구 호출이나 생각 과정 없이 일반 텍스트로 받아요.

## URL·경로·커밋을 라벨로 고르기

<kbd>⇧⌘E</kbd>를 눌러요. 화면의 URL, 파일 경로(`src/app.ts:12`, `~/notes` 같은 것), 커밋 해시마다 짧은 영문 라벨이
붙어요. 아래쪽에 가까운 것부터 붙어요.

- 라벨을 치면 **복사**해요.
- <kbd>⇧</kbd> + 라벨을 치면 **세션에 입력**해요.
- <kbd>Esc</kbd>로 닫아요.

한국어 입력 상태에서도 라벨이 그대로 돼요.

## 출력에서 찾기

<kbd>⌘F</kbd>(또는 <kbd>⌘K</kbd> → **터미널에서 찾기**)로 포커스된 터미널의 출력에서 오류 메시지나 파일 이름을
찾아요.

- <kbd>Enter</kbd> / <kbd>⇧Enter</kbd>로 다음 / 이전 결과로 가요.
- **대소문자 구분**을 켜고 끌 수 있어요.
- <kbd>Esc</kbd>로 닫으면 강조가 지워지고 키보드가 터미널로 돌아가요.

## 안전한 붙여넣기

모든 붙여넣기(<kbd>⌘V</kbd>, 끌어다 놓은 파일, 라벨 고르기, 변경사항 패널이나 미리보기 같은 패널에서 붙이는 글)는
먼저 제어 문자를 빼요(탭과 줄바꿈은 남겨요). 웹 페이지에서 복사한 글에 붙여넣기를 일찍 끝내고 명령을 실행하는 이스케이프
시퀀스가 숨어 있어도 통하지 않아요. 붙여넣기는 글만 입력하고, Enter는 항상 직접 눌러요.

## 우클릭 메뉴

터미널을 우클릭하면 이런 항목이 있어요.

- **선택 복사**(<kbd>⌘C</kbd>)와 **붙여넣기**(<kbd>⌘V</kbd>)
- **마지막 응답 복사**(<kbd>⇧⌘C</kbd>, 셸 탭에는 없어요)
- **URL·경로 고르기**(<kbd>⇧⌘E</kbd>)
- **맨 아래로**(위로 스크롤했을 때)

<Aside type="note">
  마지막 응답 복사는 로컬 프로젝트에서 돼요. [원격](/ko/docs/agents/remote-ssh/) 탭에서는 글을 선택해서 복사하세요.
</Aside>
