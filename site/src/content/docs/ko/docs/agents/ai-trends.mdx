AI 트렌드 패널은 앱을 벗어나지 않고 두 가지를 알려 줘요. 내가 쓰는 `claude`나 `codex`보다 새 버전이 나왔는지, 거기에
무엇이 바뀌었는지. 그리고 AI 개발 도구에서 개발자가 실제로 써먹을 만한 새 소식이 무엇인지요.

<Shot id="trends" caption="내 CLI: 설치된 버전과 최신 릴리스를 비교해요." />

## 패널 열기

사이드바 아래쪽의 **AI 트렌드**(신문 아이콘)를 눌러요. 아이콘에 점이 있으면 설치된 것보다 새 CLI 버전이 나왔다는
뜻이에요.

패널에는 **내 CLI**와 **기술** 두 가지 보기가 있어요. **제목 검색**으로 두 목록 모두 걸러 볼 수 있어요.

## 내 CLI

Claude Code와 Codex마다 설치된 버전(**설치됨 …** 또는 **설치 안 됨**)과 최근 릴리스를 보여 줘요.

- 뒤처져 있으면 더 새로운 릴리스와 각각 **추가된 것** 몇 줄을 보여 줘요.
- 최신이면 지금 버전에 추가된 것을 보여 줘요.

**릴리스 노트 열기**로 전체 노트를 브라우저에서 열어요.

## 기술 소식

**기술**은 새 릴리스, 라이브러리, API, 기법, 코드가 있는 논문, 눈에 띄는 새 저장소를 모아요. **지역**을 바꿀 수 있어요.

- **해외** — OpenAI News, Cursor·GitHub 변경 기록, Hugging Face 블로그와 오늘의 논문, 새 GitHub 저장소, Hacker News,
  Simon Willison, Latent Space 등.
- **국내** — GeekNews, Naver D2, 카카오·토스·우아한형제들·당근·LY 기술 블로그(AI 글만).

소식은 주제별로 묶여요. **서브에이전트**, **훅**, **에이전트 뷰**, **ADE**, **하네스**, **MCP·스킬**, **컨텍스트
엔지니어링**, **바이브·에이전틱 코딩**에 들지 않는 건 **최신**에 들어가요. 지난번에 본 뒤 새로 들어온 소식에는 점이
붙어요. 소식을 고르면 짧은 발췌가 보이고, **열기**(Hacker News 소식은 **HN 토론**도)로 열어요.

<Aside type="note" title="개발자용으로 걸러요">
  주가, 투자 유치, 실적, 경영진 인사, 소송, 정책 같은 기업 뉴스는 모든 출처에서 걸러요. AI 모델이 아니라 정해진
  규칙으로 거르기 때문에 결과가 예측 가능해요. 대신 주제 묶음에 드는 소식은 많지 않아요.
</Aside>

## 언제 가져오나요

백그라운드에서는 아무것도 가져오지 않아요. 패널을 열 때 캐시가 30분보다 오래됐으면 가져오고, ↻ **새로고침**을 누르면
바로 가져와요. 가져오지 못한 출처는 마지막 소식을 그대로 두고 패널 아래쪽에 이름이 나와요. 이미 본 소식은 일주일 뒤에
빠져요.

## Claude 요약

**✦ Claude 요약**을 고르고 **Claude로 요약**을 누르면 최근 소식을 몇 줄로 정리해 줘요.

<Aside type="caution" title="Claude 사용량을 써요">
  요약은 누를 때만 실행돼요. 제목과 짧은 발췌만 보내고, 지금 프로젝트의 Claude 계정(haiku 모델)을 써요.
</Aside>

## 트렌드를 프로젝트에 적용하기

릴리스나 소식에서 **프로젝트에 적용**을 누르면 Claude가 그 변화가 지금 프로젝트에 어떤 의미인지 분석해서 그래프로
보여 줘요. 분석은 파일을 바꾸지 않고 Claude 사용량(sonnet)을 써요. 적용하면 체크한 단계만 새
[워크트리](/ko/docs/agents/worktrees/)의 세션에 붙여 넣어요. 로컬 프로젝트에서만 돼요.
