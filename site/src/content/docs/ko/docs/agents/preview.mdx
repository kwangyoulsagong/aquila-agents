미리보기 패널은 실행 중인 웹 앱을 그 앱을 고치는 에이전트 옆, 오른쪽에 보여 줘요. 페이지에서 요소를 고르면 그 정보가
에이전트 입력창에 들어가서, "이 버튼 좀 작게"가 정확히 어떤 버튼인지 알려 줄 수 있어요.

<Shot id="preview" caption="미리보기의 앱. 고른 요소가 Claude 탭에 붙어 있어요." />

## 미리보기 열기

<kbd>⇧⌘P</kbd>를 누르거나, 탭 바의 **◫ 프리뷰**를 누르거나, <kbd>⌘K</kbd> → **미리보기 보기**를 실행해요.

실행 중인 개발 서버가 있어야 해요. 찾지 못하면 터미널이나 [Run 슬롯](/ko/docs/agents/run/)에서 서버를 켜거나,
**주소** 칸에 직접 입력하세요.

## 주소를 찾는 방법

Aquila는 두 곳에서 주소를 모아 최신순으로 보여 줘요.

- 프로젝트의 **`.claude/launch.json`** — `configurations` 아래 항목마다 `port`나 `url`.
- **터미널 출력** — 이 프로젝트의 터미널이나 실행이 출력한 `localhost` 주소(`http://127.0.0.1:…`, `0.0.0.0`,
  `[::1]`도 `localhost`로 쳐요).

**찾은 개발 서버**에 모여 있고, 마지막에 쓴 주소는 기억해 둬요.

```json title=".claude/launch.json"
{
  "configurations": [
    { "name": "web", "port": 5173 }
  ]
}
```

<Aside type="tip" title="워크트리">
  미리보기는 포커스된 탭을 따라가요. [워크트리](/ko/docs/agents/worktrees/)의 탭이면 그 워크트리의 주소,
  `launch.json`, 기억한 URL을 쓰고, 패널 머리에 브랜치가 보여요. **포트 시작 번호**가 있으면 그 워크트리의 `PORT`
  범위에 있는 주소가 먼저 와요.
</Aside>

## 다른 너비로 보기

**너비**에서 **맞춤**, **390**, **768**, **1440** 중에 골라요. 패널보다 넓은 너비는 줄여서 보여 주기 때문에, 페이지의
미디어 쿼리는 실제 그 너비로 동작해요.

너비만 바뀌어요. 모바일 브라우저나 터치 입력을 흉내 내지는 않아요.

## 요소를 골라 에이전트에 알려 주기

<Steps>

1. 보낼 Claude나 Codex 탭에 포커스를 둬요.

2. **요소 선택**을 눌러요. 포인터를 따라 요소의 태그, 클래스, 크기가 강조돼요.

3. 요소를 클릭해요. (<kbd>Esc</kbd>로 취소해요.)

4. 그 탭에 프롬프트가 붙어요. 페이지, CSS 선택자, 요소의 텍스트, 속성, 크기, 계산된 스타일, 컴포넌트 이름(React나
   Vue면 알아낼 수 있을 때)이 들어가고, 이어서 잘라 낸 스크린샷이 붙어요.

5. 바꿀 내용을 적고 <kbd>Enter</kbd>를 눌러요.

</Steps>

버튼에 보낼 곳(**→ 탭 이름**)이 표시돼요. 포커스된 Claude·Codex 탭이 없으면 클립보드로 복사해요. 탭이 답을 기다리는
중이어도 질문 한가운데 끼어들지 않게 클립보드로 복사해요. 먼저 답한 뒤 <kbd>⌘V</kbd>로 붙여 넣으세요.

## 다른 버튼

| 버튼 | 하는 일 |
|---|---|
| **뒤로**, **새로고침** | 페이지를 이동해요. |
| **DevTools** | 미리보기의 개발자 도구를 열어요. |
| ↗ | Chrome으로 열어요(Chrome이 없으면 기본 브라우저). |
| ⛶ | 프리뷰만 창 가득 크게 보여 줘요. 다시 누르면 원래대로 돌아와요. |

<Aside type="note">
  창이나 명령 팔레트가 열려 있는 동안에는 미리보기가 잠깐 숨었다가 닫히면 다시 보여요. 새 창으로 여는 링크는
  브라우저로 열려요. 미리보기는 로컬 프로젝트에서만 돼요.
</Aside>
