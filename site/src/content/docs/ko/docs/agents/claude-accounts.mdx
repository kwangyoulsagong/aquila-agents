Aquila는 Claude 계정 두 개를 알고 있고, 프로젝트마다 하나를 골라요.

| 계정 | 대응하는 명령 | 로그인 위치 |
|---|---|---|
| **공용** | `claude` | `~/.claude` (평소 쓰는 Claude Code 로그인) |
| **개인** | `claude-personal` | `~/.claude-personal` |

회사 레포는 업무 계정, 개인 프로젝트는 개인 계정으로 나눠 쓰는 식이에요. 두 계정 모두 같은 `claude`를 실행하고,
세션마다 설정 폴더(`CLAUDE_CONFIG_DIR`)만 다르게 넘겨요. 그래서 계정마다 로그인, 기록, 사용량이 따로예요.

<Shot id="accounts" caption="탭 바의 계정 스위치는 선택한 프로젝트에 적용돼요." />

## 프로젝트의 계정 고르기

탭 바 오른쪽의 **Claude 계정** 스위치에서 **공용**이나 **개인**을 누르면 돼요. 선택한 프로젝트에만 바뀌어요.

이런 곳에서도 정할 수 있어요.

- 프로젝트를 추가할 때(추가 창의 **Claude 계정** 칸)
- 사이드바에서 프로젝트를 우클릭 → **Claude 계정**
- **프로젝트 설정…**(프로젝트 우클릭)

<Aside type="caution" title="새 세션부터 적용돼요">
  스위치는 그 프로젝트의 **새** Claude 세션부터 적용돼요. 이미 열린 탭은 시작할 때의 계정을 그대로 써요. Claude 탭마다
  계정 배지가 붙어 있어서 구분할 수 있어요.
</Aside>

## 개인 계정 설정하기

아직 로그인하지 않은 계정이 있으면 스위치 옆에 **개인 설정** 버튼이 떠요.

<Steps>

1. **개인 설정**을 눌러요. 폴더가 있는지, 로그인됐는지 보여 줘요.

2. **폴더 만들고 로그인**을 눌러요. `~/.claude-personal`을 만들고 그 폴더를 쓰는 Claude 세션을 열어요.

3. 열린 세션에서 Claude Code가 안내하는 대로 로그인해요. 로그인이 확인되면 버튼이 사라져요.

</Steps>

공용 계정은 버튼이 **Claude 열어서 로그인**이에요. Claude 세션을 열어 주니 거기서 로그인하면 돼요.

### 내 터미널에서도 `claude-personal` 쓰기

같은 창에 **터미널에서도 claude-personal 쓰기**가 있어요. **미리보기**로 `~/.zshrc` 끝에 추가할 한 줄을 확인하고,
**…에 추가** 버튼을 누르면 추가돼요. 누르기 전에는 아무것도 쓰지 않고, 셸에 이미 `claude-personal`이 있으면 바꾸지
않아요.

## 사용량과 컨텍스트 보기

**사용량 게이지.** 사이드바 아래쪽에 로그인된 계정마다 막대가 두 개 있어요. 지금 **5시간** 구간(리셋 시각 포함)과
**주간**이에요.

- **실제**는 Claude의 `/usage`(Codex는 세션 기록)에서 읽은 값이에요. claude.ai와 다른 기기 사용량도 들어가요.
- **추정**은 이 Mac의 Claude 기록으로 계산한 값이라 claude.ai나 다른 기기에서 쓴 양은 빠져요. 한도에 한 번도 닿은
  적이 없으면 비율 없이 토큰 수만 보여요.
- 90%에 닿으면 macOS 알림이 한 번 오고, 다른 계정에 여유가 있으면 **… 계정으로 새 Claude** 버튼이 떠요.

**컨텍스트 게이지.** 로컬 Claude 탭마다 대화의 컨텍스트 창이 얼마나 찼는지 작은 고리로 보여 줘요. 60%부터 숫자가
나오고 주황색이 돼요(`/compact`나 새 세션을 고려할 때예요). 85%부터는 빨간색이에요.

<Aside>
  컨텍스트 고리는 Claude의 상태 줄을 이용해요. Claude 설정에 직접 만든 `statusLine`이 있으면 Aquila는 그걸 건드리지
  않고, 그 탭에는 고리가 없어요.
</Aside>

## 원격 프로젝트

SSH 호스트의 프로젝트는 계정 스위치를 쓰지 않아요. 대신 프로젝트 설정에서 **호스트의 Claude 설정 폴더**를 정할 수
있어요. [원격 서버(SSH)](/ko/docs/agents/remote-ssh/)를 보세요.
